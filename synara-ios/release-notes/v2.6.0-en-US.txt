Synara 2.6.0 fixes signing in when the server address is a proxy whose name differs from the homeserver's own name: the username is now sent as typed and the Matrix ID comes from the server. The app and its notification service also declare the system APIs they use in their privacy manifests.

Please test: signing in with a plain username and with a full Matrix ID (on a new install and after signing out), signing in again on the same device, notifications (including previews in the notification service), GIFs and the Connection Lost banner, to confirm nothing regressed.
