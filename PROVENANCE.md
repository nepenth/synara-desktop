# Provenance

Synara is a native-first Matrix client for macOS, Linux, and iOS. The desktop
clients use Tauri and React; iOS uses SwiftUI; all supported clients consume the
shared Rust application core.

Synara includes AGPL-3.0-only derived code from its prior upstream lineage.
