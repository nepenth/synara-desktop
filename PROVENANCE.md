# Provenance

Synara Desktop is the Tauri desktop wrapper for Synara, maintained as its own application and release line.

Synara Desktop includes code derived from Cinny Desktop, originally published by the Cinny contributors under the GNU Affero General Public License version 3.0.

Original upstream project:

- https://github.com/cinnyapp/cinny-desktop
