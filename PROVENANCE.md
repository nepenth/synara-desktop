# Provenance

Synara Desktop is the Tauri desktop wrapper for Synara, maintained as its own application and release line.

Synara Desktop includes code derived from LegacyClient Desktop, originally published by the LegacyClient contributors under the GNU Affero General Public License version 3.0.

Original upstream project:

- https://github.com/legacyclient/legacy-client-desktop
