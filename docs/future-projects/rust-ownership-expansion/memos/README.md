# Research Memos

Store first-pass ownership decisions here as
`ROE-XX-short-name-memo.md`, using
[`RESEARCH-MEMO-TEMPLATE.md`](../RESEARCH-MEMO-TEMPLATE.md).

Memos are docs-only evidence and recommendations. They do not authorize product
code or changes to accepted architecture. Their accepted ownership verdicts
are not claims that every affected feature is complete or proven; unresolved
defects, evidence, parity, and product decisions live in the
[residual action register](../program/ACTIONS.md).

The completed 2026-09-01 run used one worker PR and an independent exact-HEAD
verdict for each memo. Its protocol is preserved only as historical provenance
in [program/OPERATING.md](../program/OPERATING.md). Future work uses a newly
chartered branch and current review policy.
