# Synara 2.1.41

Synara 2.1.41 improves conversation readability on iPhone and Linux, adds a
first-class iPad conversation canvas, and includes an agent status widget
example. It also tightens Matrix compatibility checks around recent Synapse
changes.

## iPhone and iPad

- Typed and pasted composer text stays legible in dark appearance.
- Sending from unread history returns to the newest message. Saved Later items
  open reliably on iPhone and beside the list on iPad.
- A regular-width iPad window keeps the room list and conversation visible
  together. Compact windows retain stacked navigation.
- Notification service extension production feature and archive checks are
  covered by delivery tests.

## Linux and desktop

- The small panel icon shows a red dot for unread messages. Its menu and
  tooltip retain the count. Numeric dock badges remain dependent on desktop
  launcher support; Pop!_OS 24.04 COSMIC does not currently consume the
  existing Unity badge signal.
- Message spacing is included in each measured timeline row, preventing
  adjacent messages from overlapping during virtualization.
- `examples/agent-status-widget` serves a sample priority/status list that
  agents can update through a token-protected local API.

## Matrix compatibility

- The disposable integration harness now uses Synapse 1.161.0 and includes a
  room-version-12 smoke script for a future Synapse 1.162 server.
- Restricted space hierarchy entries retain allowed room IDs and explain
  membership or invite requirements.
- Profile edits show a useful retry message when the server rate-limits a
  request.

## Validation

The implementation is in feature PR #1157. Local repository, frontend,
browser, iOS unit, and focused iPhone/iPad simulator checks are recorded
there. This release candidate requires a green Quality gate, including full
iOS simulator unit and UI suites, and Desktop Package Smoke. The Debian
package is intended for Pop!_OS 24.04 COSMIC live smoke before the release
tag is pushed.
