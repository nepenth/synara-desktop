# Synara 2.1.6

Synara 2.1.6 is a coordinated macOS, Linux, and iOS product release. It
lands the remaining native Core owners for settings and SDK surfaces
that were still leftover or GAP after 2.1.5.

## Settings Owners

- Homeserver push-rule editor: keywords, default mode, and mentions.
- 3PID / email attach and delete. Passwords and client secrets stay
  method arguments, not Core JSON fields.
- Ignored-user list snapshot, ignore, and unignore.
- iOS avatar upload uses `upload_avatar` bytes as method args, then
  `set_own_avatar`.
- iOS outgoing typing follows Hide Typing & Read Receipts.

## Remaining Core Owners

- Per-room notification mode `all` / `mentions` / `mute` / `default`.
  Default deletes user-defined room rules. iOS room details include
  Default; desktop mute icons use the bulk native snapshot.
- iOS HTTP pusher register/delete (push key as a method argument).
- iOS media upload and send attachment; plain `mxc://` download.
- iOS backup restore via `restore_backup(recovery_secret)`. Leftover
  `recover` remains on SharedCore for leftover tests.
- User-directory search for invite prompts.
- Message search via Client-Server `/search`.
- Join-rule write (`public` / `invite` / `knock` / `restricted` /
  `knock_restricted`).
- Presence SET: iOS Account and desktop Profile Online / Away /
  Offline. Own user id comes from the live session.
- iOS `get_own_profile` seeds the display-name field from the
  homeserver.

## Upgrade Notes

- Existing native sessions should restore normally.
- Leftover SharedCore FFI (`set_notification_mode`, `pusher_set`,
  `media_upload`, `media_download`, `recover`) stays fail-closed.
- macOS updates through the Tauri updater. Linux updates through the
  pacman repo or the `.deb`. iOS updates through TestFlight.

## Validation

The product PR's Quality gate, including iOS simulator tests and
desktop package smoke, was green before this version bump. Version-only
bumps reuse a proven Quality gate on the tagged SHA.
