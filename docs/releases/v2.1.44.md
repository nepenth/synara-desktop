# Synara 2.1.44

Synara 2.1.44 improves notification diagnostics and agent notification controls on desktop, iPhone, and iPad, and fixes desktop unread navigation and live message layout.

## Notifications and agent controls

- Configure exact agent Matrix IDs and separate Tool activity, Commentary, and final/other response notifications in Settings → Notifications. Preferences sync through your Matrix account across supported Synara clients. Verified approval prompts bypass these category filters.
- Fresh, eligible Hermes approval prompts use Time Sensitive delivery and retain Approve once/Deny actions. Critical delivery is supported only when a build has Apple's approved Critical Alerts entitlement and the device authorizes it; this standard release does not claim that restricted capability.
- Notification previews resolve from authenticated, decrypted Matrix events. Generic fallback content discards unverified gateway presentation. Stricter event-reference parsing and fixed diagnostic stages make payload and preview-fetch failures easier to distinguish.
- Copy or share a privacy-safe iOS diagnostics report containing app/build information, notification readiness and recent delivery stages, without message text, Matrix identifiers or push tokens.

Desktop and iOS foreground presentation can suppress excluded agent categories. Standard iOS background notifications can hide an excluded preview but still display a generic alert; complete background suppression requires Apple's restricted Notification Service Extension Filtering entitlement.

## Desktop

- Direct Messages unread indicators use the native direct-room classification, consistent with destination lists, Mark as Read and room/thread navigation.
- Remeasure live edited Hermes lists and code blocks to correct stale row offsets and reduce message overlap on desktop.
- Signed macOS packages embed and validate their matching Time Sensitive Developer ID profile. iOS app and notification extension profiles have been refreshed for the same capability.
