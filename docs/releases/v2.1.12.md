# Synara 2.1.12

Synara 2.1.12 fixes the iOS suspension crashes reported from TestFlight by
making the Matrix SDK's required background stop part of the app's authoritative
lifecycle path.

## iOS Background Sync Ownership

- UIKit now begins a bounded background assertion when Synara enters the
  background and keeps the process runnable until the retained native Matrix
  `SyncService` has completed its stop operation.
- The shared Rust core exposes a privacy-safe UniFFI stop operation that awaits
  `SyncServiceOwner.stop()` without logging out, destroying the crypto store,
  replacing the Matrix client, or changing the session generation.
- Foreground activation waits for any pending stop before restarting the same
  retained owner. A rapid foreground-to-background reentry suppresses the stale
  foreground restart, preventing sync from reopening SQLite work after the app
  has returned to the background.
- The native room-list observer is stopped before the SDK service, while the
  notification extension remains unable to start or stop the product sync
  owner.

## Diagnostics

- Privacy-safe signposts record background pause start/completion, background
  assertion expiration, suppressed stale foreground resumes, and foreground
  restart. They contain no Matrix identifiers, credentials, paths, or SDK error
  text.
- Submitted TestFlight reports consistently showed RunningBoard termination
  `0xdead10cc` while Matrix SDK SQLite writes held a file lock at suspension.
  The previous iOS `pauseForBackground()` implementation was a no-op even though
  the Matrix SDK explicitly requires `SyncService.stop()` when the app moves to
  the background.

## Validation

- PR #1053 passed the complete clean Rust workspace gate and iOS simulator gate,
  including generated Apple bindings, native boundary checks, clippy, desktop
  and shared-core tests, and the aggregate Quality gate.
- Local validation passed 788 shared-core unit tests with two ignored, every
  shared-core integration contract, 588 iOS tests with two skipped, the focused
  21-test lifecycle suite, Swift scaffold validation, Matrix-native guardrails,
  formatting, version, and workflow-policy checks.
- Focused regressions cover native stop/restart with the same session generation,
  notification-extension rejection, stop-before-resume ordering, initial
  activation, assertion expiration, duplicate background entry, and rapid
  lifecycle reentry.
