# Synara 2.1.16

Synara 2.1.16 refreshes the existing Synara app icon for clearer, more
consistent presentation across iOS, macOS, Linux, and Windows without replacing
the identity users already recognize.

## App Icon

- Preserved the current wing-and-network identity while enlarging its visual
  mass, simplifying fragile highlights, and strengthening the small-size form.
- Added platform-appropriate exports: unmasked opaque iOS and macOS artwork,
  transparent-corner Linux/Windows assets, complete ICNS and ICO containers, and a
  one-color Linux symbolic icon for high-contrast themes.
- Installed the Linux symbolic icon through both Debian and Arch packaging.
- Added a deterministic asset generator and a reviewed hash manifest so every
  shipped size can be reproduced and audited.

## Release Safety

- Added fail-closed icon-only CI routing. Icon releases run focused asset and
  packaging-contract checks while skipping unrelated hour-plus runtime suites;
  any non-icon production change automatically restores the full test matrix.
- Validated all 33 platform assets for exact dimensions, color and alpha rules,
  transparent desktop corners, ICNS/ICO structure, Linux symbolic safety, and
  reviewed hashes.
- Built and code-signature-verified the local macOS application bundle.

## What to Test

- Compare Synara with neighboring apps in the macOS Dock at normal and small
  magnification; the mark should feel larger, cleaner, and more balanced.
- Confirm the icon remains crisp in iOS Home Screen, Settings, notifications,
  and the app switcher.
- On Linux, confirm the full-color icon appears in the application grid and the
  symbolic mark remains recognizable in high-contrast contexts.
