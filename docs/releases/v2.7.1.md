# Synara 2.7.1

Synara 2.7.1 brings link previews back on desktop and fixes X post cards.

## Desktop

- Link previews: the first link in a message shows a card with the page's title, description and image. Previews also work in encrypted rooms, because your device fetches the page itself instead of asking your homeserver. The site can see your IP address. Turn previews off in Settings → General → "Link previews".
- Previews never reach your local network or private addresses. Redirects, size and time are all limited.
- X posts: x.com and twitter.com links show the post card again. X's embed service had started rejecting Synara's requests.

## iOS

- No changes apart from the version number. Link previews on iOS will come in a later release.

## Distribution

The coordinated tag workflow validates the release and publishes signed and notarized macOS downloads and updater metadata, Linux APT and pacman packages, Windows installers (checked to launch to the sign-in screen first), and the internal iOS TestFlight build.
