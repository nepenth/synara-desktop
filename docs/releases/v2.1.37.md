# Synara 2.1.37

Synara 2.1.37 persists Approvals Recent history across devices, quiets desktop
chrome, restores remote Explore browsing, enriches Devices, and steadies native
timeline scrolling.

## Approvals history and notifications

- Decided agent approvals are written to
  `in.synara.agent_approval_history` account data so Approvals › Recent
  survives restarts and syncs. Recent prefers a local inbox decision over
  homeserver account data; summaries redact path-like args and secret-like
  assignments.
- Desktop and iOS share the same Recent list through UniFFI
  `agent_approval_history_snapshot`. The empty "Full approval prompt" block is
  gone; the Command block and no-command fallback remain.
- Linux OS notifications dismiss when a room is focused or an approval is
  decided. macOS stays a no-op for that command.

## Quiet UI, Explore, and Devices

- Composer formatting, Explore chips/menus, Personal Notes, and Settings
  controls use the quiet action recipe. Welcome and About link to GitHub
  Sponsors.
- Explore can browse other homeservers again, with classified federation and
  network errors instead of a generic unavailable state. Unknown public-room
  types are skipped rather than failing the page.
- Settings › Devices shows trust chips, a This device marker, identity-key
  fingerprints, and first-seen. Cross-signed and SAS-only sessions both read
  as Verified. Dehydrated sessions read as Backup device.

## Native timeline

- Measured row heights, reserved media boxes, and same-frame follow-live keep
  the live tail stuck without yanking a parked history row. Prepends, in-row
  growth, date separators, and reactions hold the parked visual top.
