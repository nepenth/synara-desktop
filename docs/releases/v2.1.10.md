# Synara 2.1.10

Synara 2.1.10 delivers a coordinated readability and interaction pass across
iOS, macOS, and Linux, with faster mobile composition and reorderable synced
room notes.

## Cross-Client Navigation

- Room lists use compact channel markers and Slack-like `# Room Name` labels
  instead of decorative room avatars, making dense lists easier to scan.
- Favorites and rooms retain their own ordering while selected, unread,
  notification, and timestamp states use a clearer visual hierarchy.
- Room headers and navigation surfaces now share the same semantic spacing and
  color roles across desktop clients.

## Message Readability

- Dark-mode foregrounds and backgrounds use a softer semantic ramp that reduces
  glare without sacrificing tested contrast.
- Timeline measure, line height, vertical rhythm, author metadata, replies, and
  message grouping are tuned for long technical conversations.
- Rich-message tables use clearer headers, alternating rows, cell padding, and
  restrained borders; inline code and fenced code use coordinated syntax
  colors and surfaces.
- Composer controls have a more legible hierarchy and remain visually attached
  to the conversation without competing with message content.

## iOS Interaction and Accessibility

- Room notes can be reordered with drag gestures and retain their account-synced
  ordering across clients.
- Composer measurement avoids unnecessary synchronous layout work, reducing
  perceptible latency while typing and preserving Matrix formatting behavior.
- Dynamic Type changes invalidate composer measurement correctly, including at
  Accessibility Extra Extra Large sizes.
- Room, Settings, Notifications, and timeline surfaces stay visually continuous
  in light and dark appearance, and final content remains clear of the floating
  tab bar.
- Notification disclosure rows expose complete accessibility behavior rather
  than relying on a visually implied control.

## Desktop Notes and Settings

- Desktop room-note reordering and conflict handling align with the iOS model.
- Settings tiles, sidebars, and narrow-window layouts use the same semantic
  surface and text system while preserving responsive behavior.
- Existing user-selected themes remain intact; the new derived palette applies
  without overwriting stored theme choices.

## Validation

- The complete pull-request Quality gate passed at the feature merge commit,
  including 62 executed iOS UI tests, the generic-device Release build, Rust
  and Node gates, six disposable-Synapse proofs, and macOS, Debian, and Arch
  package smokes.
- Focused iOS unit and UI coverage verifies note reordering, composer Matrix
  formatting, semantic theme ramps, Dynamic Type, notification disclosure, and
  floating-tab-bar clearance.
- Desktop validation covers TypeScript, ESLint, Prettier, the modernization
  suite, production build, native timeline formatting, room lists, themes, and
  room-note ordering.
- Grok 4.6 High reviewed the holistic cross-client implementation; accepted
  findings were incorporated before the final green run.

## What to Test

- Reorder room notes on iOS, then confirm their order on a desktop client using
  the same account.
- Compose a long or rapidly typed message on iOS and confirm input remains
  responsive at the default and Accessibility Extra Extra Large text sizes.
- Compare room lists, long technical messages, rich tables, replies, and code
  in light and dark appearance on iOS and desktop.
- Scroll to the final row or action on every iOS tab and confirm it remains
  comfortably above the floating tab bar.
