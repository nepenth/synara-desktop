# Synara 2.1.26

Synara 2.1.26 improves desktop window controls, room and search menus, and
notification decisions while strengthening client and release boundaries.

## Desktop Experience

- macOS uses an overlay titlebar with draggable headers and room for the native
  window controls. Linux gains an integrated titlebar with minimize, maximize,
  and close controls.
- Room menus, member filters, and message search use consistent floating surfaces
  and interactive depth.
- Unread placement on an already-live timeline can resume live following after
  the visible tail matches Core's current tail. Historical context windows keep
  the explicit Jump to latest action, including on iOS; reaching their bottom
  does not silently replace history or acknowledge unseen messages.

## Notifications And Security

- Desktop notification candidates flow through the shared Core decision stream.
  Recent-event deduplication and retained identifiers are bounded, and rejected
  candidate conflicts no longer evict valid pending work.
- Explicit Matrix mention metadata takes precedence over legacy body matching,
  reducing unintended highlights and notifications.
- The privileged desktop window restricts document navigation to the exact
  application origin and port.
- Updated Rust and JavaScript dependencies include fixes for vulnerable
  Browserslist and fast-uri build-tool dependency paths.

## Release Reliability

- Build manifests, configuration, generated runtime, packaging, and workflow
  changes receive the relevant CI validation instead of filename-based skips.
- Release branches and explicit iOS validation labels retain their simulator
  gates. TestFlight export retry handling and exact-tag release validation are
  included from the recent release-tooling changes.
- Desktop, iOS, and package versions are synchronized at 2.1.26, including the
  iOS build number.

## What To Test

- Open an unread room, scroll to its live tail, and check automatic read state.
  Open an older event and confirm newer unseen messages remain unread until
  explicitly jumping to latest and viewing them.
- Check macOS traffic-light spacing, header dragging, and Linux titlebar controls
  on the target desktop environment.
- Exercise mention notifications, repeated candidate delivery, and ordinary
  external links without navigating the privileged window away from the app.

Automated results are recorded in PR #1101 and the v2.1.26 Release workflow.
Physical iOS push delivery, native window geometry, and interactive package
installation remain manual validation items; this release note does not claim
new physical-device or live-account smoke evidence.
