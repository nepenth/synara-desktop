# Synara 2.1.36

Synara 2.1.36 adds a native Approvals center, inbox notifications, idle
approval badges that do not farm timelines, and desktop room-list polish.

## Approvals center

- The rail and `/approvals/` page list pending agent approvals from Core
  `matrix_agent_approvals_list`. Approve and deny still go through
  `matrix_agent_approval_decide`.
- Desktop and iOS expose the same list through UniFFI/UDL wrappers.
- Opening a room waits briefly for inbox pagination, then fail-opens so a stuck
  discovery page cannot fail the user's room.

## Inbox notifications and idle badges

- Inbox notifications are native `matrix_inbox_notifications` instead of the
  JavaScript stub.
- Idle room-list approval badges use the latest event only. They do not open a
  timeline per joined room.
- Opening Approvals runs bounded discovery: at most 32 observers, a 30s lease,
  and spaces skipped. Rail `!` alarms only when a room is incomplete or
  errored. Leaving Approvals drops leftover discovery gaps so idle rooms do
  not stay alarming.
- Encrypted last messages stay off the cheap index until a local decrypt
  succeeds, then appear on the idle list.

## Desktop polish

- The room-list virtualizer keeps scroll-margin so the focused row stays in
  view. Avatar object URLs are cached. Composer and menu CSS are tightened.

rail and page list pending prompts, open a room from that list, then leave
