# Synara 2.1.39

Synara 2.1.39 polishes the 2.1.38 native timeline, search, badges, widgets,
and chrome: richer markdown preview, a 7-day date rail, quieter live-tail
loading, findable widgets, honest call status, and unread app-icon badges.

## Timeline and attachments

- Markdown attachments render lists, GFM tables, task prefixes, and
  strikethrough, with Copy in the preview header. Download remains.
- The date rail is a 7-day calendar. Hover chips sit above the messages.
  Older ticks jump with `timestamp_to_event`.
- Historical loading chrome stays at the top. Wheel past the newest message
  does not strobe “Loading newer messages”. First paint measures history
  edges without a scroll event.

## Search, inbox, and reactions

- In-room Media and Files can browse the last 7 days with an empty search
  term. Hits keep a closed msgtype so type chips work.
- Reaction search keeps prior results when pack lists are replaced. Inbox
  Notification Messages no longer blink on room-list identity ticks.

## Widgets, calls, and badges

- Widgets live under Settings → General on this device only and stay
  default off.
- Call chrome reports MatrixRTC discovery. Start/Join is not offered.
- Desktop dock/tray and iOS app-icon badges follow the unread summary.

## Quiet chrome

- Settings, room, and space nav use a resting gap. Invite matches other
  menu rows. Composer plus dismisses on outside click. Native Appearance
  no longer shows a Message Layout card or other-client names.

## Validation

#1152 merged to `main` as `d56110e4` after its required Quality gate. iOS
simulator unit and UI suites are skipped on ordinary PRs and run on this
`release/v2.1.39` candidate.

The maintainer authorized merging #1152 and cutting this release. Final
signed-artifact install/update and live cross-client UI checks were not
repeated here.
