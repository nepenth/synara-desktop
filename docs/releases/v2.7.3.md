# Synara 2.7.3

Synara 2.7.3 shortens long links in messages on desktop and iOS.

## Desktop and iOS

- A long web address written out in a message shows as its site and path, such as `yahoo.com/…/patrick-stewart-star-of-x-men-and-…`, instead of filling the chat. Tracking queries are left out and marked with `…`, the path is cut at a word break, and the site is never cut, so you always see where a link goes.
- The link still opens the whole address. On desktop, hovering shows it; on iOS, long-pressing shows it. Messages are sent unchanged, so other clients see what was written.
- Links with their own text, short addresses and search results keep their text.
- Turn it off in Settings → General → "Shorten long links" on desktop, or Settings → GIFs & Link Previews → "Shorten Long Links" on iOS (on by default).

## Distribution

The coordinated tag workflow validates the release and publishes signed and notarized macOS downloads and updater metadata, Linux APT and pacman packages, Windows installers (checked to launch to the sign-in screen first), and the internal iOS TestFlight build.
