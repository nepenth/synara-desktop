# Synara 2.1.3

Synara 2.1.3 is a coordinated macOS, Linux, and iOS product release. It
completes live SAS device verification end to end and polishes the desktop
UX pass from 2.1.2 (chrome, room sort, Appearance, reconnect banner, jump
to latest).

## Device Verification

- Desktop verification is a single Router-level overlay. Starting from
  Settings no longer opens a second dialog that dies when Settings closes.
- The inbox keeps the in-progress flow instead of always taking the first
  request. Confirm and mismatch stay disabled until emoji or decimal codes
  exist.
- Native SAS emits live wake-ups on login, register, and restore, with a
  poll fallback. Device list and Unverified tab refresh when verification
  finishes.
- iOS cannot swipe away a non-terminal SAS sheet. Security settings follow
  verification updates and hide Verify This Device once this session is
  trusted.

## Rooms And Appearance

- Favorites and Rooms each keep their own recent/name sort.
- Rooms is title-case. Sort icons sit on the section headers.
- Chat chrome sits closer to the rail and room list greys.
- Accent Color shows the theme primary actually in use. Twitter Emoji is
  gone from Appearance.
- Connection Lost waits for lasting Offline. Connected only follows a Lost
  banner the user saw.

## Timeline

- Jump to latest stays visible whenever the loaded window is not the live
  tail (unread, focused, restored, or scrolled up).

## Upgrade Notes

- Existing native sessions should restore normally.
- macOS updates through the Tauri updater. Linux updates through the pacman
  repo or the `.deb`. iOS updates through TestFlight.

## Validation

The release is gated by renderer lint and type checking, modernization tests,
Rust workspace and desktop-shell tests, iOS simulator tests, macOS bundle
validation, and Linux Debian and Arch package validation. Version-only bumps
reuse a proven Quality gate on the tagged SHA.
