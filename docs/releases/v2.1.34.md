# Synara 2.1.34

Synara 2.1.34 fixes the desktop Developer Tools crash and improves iOS device verification.

## Desktop room settings

- Open Developer Tools on native rooms without crashing, and keep Room ID visible for copying.
- Read room state and account data through the native room projection.
- Show recoverable error screens for settings panels and routes instead of the default application error page.

## iOS verification

- Size verification sheets to their content, with a compact emoji comparison and consistent buttons.
- Keep large-text layouts scrollable so the comparison values and actions remain reachable.
- Acknowledge completed verification flows once, preventing buffered completion events from reopening the result after dismissal.
- Show dismissal failures with a retry opportunity, without clearing a newer request.
- Read this device's trust separately from comparison completion before displaying "Device verified."

## Validation

Both feature PRs passed their required Quality gates before merging to main. The Developer Tools PR also passed macOS, Debian, and Arch package builds. The iOS implementation passed 732 unit tests, including six new verification presentation regressions, with three skipped and none failed.

The initial iOS UI run failed to launch in Xcode before any assertions or screenshots were recorded. The release candidate runs the full iOS suites and desktop package builds on the combined source; the earlier launch failure is not a passing UI result. Details are in [the verification presentation report](../reviews/2026-09-10-ios-verification-flow.md).

The user authorized merging both fixes and starting this release. Physical-device, final signed-artifact install/update, and live cross-client UI checks were not repeated for this version.
