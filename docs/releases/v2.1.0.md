# Synara 2.1.0

Synara 2.1.0 is a cross-platform security and reliability release for iOS, macOS, and Linux. It also incorporates the recent timeline, room-interaction, agent-card, and native Matrix boundary improvements validated across the desktop and mobile clients.

## Security And Privacy

- Matrix access and refresh tokens remain exclusively in native credential storage. Retired renderer, localStorage, service-worker, and token-bearing desktop IPC paths are removed and cleaned up after a proven native login or restore.
- Remote homeservers and identity servers now require HTTPS. Plain HTTP remains available only for exact loopback development hosts.
- Matrix media, attachment exports, streaming file saves, invite avatars, and notification-service responses enforce bounds before buffering attacker-controlled content.
- Desktop temporary export files use private, collision-resistant creation, and concurrent export reservations have an aggregate size cap.
- Diagnostics redact credential values, bearer authorization headers, and escaped JSON secrets.
- iOS lock-screen message previews now default off and remain an explicit user choice.

## macOS And Linux

- Session bootstrap is identity-only and no longer performs a duplicate SDK restore before the application shell mounts.
- Orphaned or unrestorable native sessions can be cleared safely from the startup recovery path.
- Room actions use contextual menu interactions for read state and history loading; timeline navigation uses compact icon controls.
- Recent fixes cover room member fallback data, timeline date presentation, agent activity cards, encrypted-session restore, and native token rotation persistence.
- JavaScript and Rust dependency advisories addressed in this release are updated without reintroducing renderer credential ownership.

## iOS And TestFlight

- Notification previews are privacy-preserving by default, and notification event resolution is bounded before decoding.
- Shared Matrix contracts, encrypted-room behavior, rich messages, reactions, attachments, threads, room state, and agent interactions include the latest native-core fixes.
- TestFlight promotion now publishes versioned "What to Test" notes automatically for the exact uploaded build.

## Upgrade Notes

- Existing native sessions should restore normally. Retired renderer credential entries are purged only after native credentials have been proven usable.
- Users configured against a remote `http://` homeserver must move that deployment to HTTPS. `localhost`, `127.0.0.1`, and IPv6 loopback remain supported for development.
- If native credential storage is unavailable or inconsistent, Synara fails closed and offers a clean sign-out path instead of falling back to browser storage.

## Validation

The release is gated by renderer lint, type checking, deterministic modernization tests, Rust workspace and desktop-shell tests, dependency audits, iOS simulator tests, macOS bundle validation, Linux Debian and Arch package validation, and live disposable-homeserver Matrix proofs.
