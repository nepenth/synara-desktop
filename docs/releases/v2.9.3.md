# Synara 2.9.3

Synara 2.9.3 lets you hide the room list to give a room the full window, keeps file paths in messages from turning into web links, updates the room list with far less work, and tidies Hermes question cards.

## Desktop

- Hide the room list: the new button at the top of the rail, Cmd+Shift+D (Ctrl+Shift+D on Linux and Windows) or View → Show/Hide Room List on macOS slides the list into the rail and back. It keeps its scroll position, search and collapsed sections, and remembers your choice on this device. While it is hidden on a space, the button shows that space's unread; on Home, Home's badge already does.
- Links: a file path or file name in a message (`submission/README_SUBMISSION.md`, `setup.py`) is no longer turned into a web link, and link previews follow the same rule.
- Room list: updates reuse the rooms that did not change instead of rebuilding every room, about 6 ms down to 0.4 ms per update.
- Question cards: the number and skip reactions Hermes adds to a question card no longer repeat under it as reaction pills; the card already shows the choices and your answer.

## iOS and iPad

- Links: file paths and file names in messages stay plain text.
- Question cards: the number and skip reactions no longer repeat under the card.

## Distribution

The coordinated tag workflow validates the release and publishes signed and notarized macOS downloads and updater metadata, Linux APT and pacman packages, Windows installers (checked to launch to the sign-in screen first), and the internal iOS TestFlight build.
