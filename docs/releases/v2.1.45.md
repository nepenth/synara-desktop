# Synara 2.1.45

Synara 2.1.45 improves desktop connection recovery and updates dependencies and build tooling across desktop and iOS.

## Desktop connection recovery

- Restored sessions can start syncing without waiting for a separate homeserver metadata request to succeed.
- Connection Retry waits for native sync recovery and shows recovery progress or failure clearly.
- Correct the native sync startup call used during restoration and wake recovery.

## Dependencies and build tooling

- Update Rust and JavaScript dependencies, including the ESLint 10 and Prettier 3 migration.
- Adopt pinned Kache compiler caching across supported local Rust builds and CI, with separate build families and designated cache writers.
- Preserve unchanged generated Apple bindings and frameworks, narrow Rust compilation inputs and reuse bounded native Xcode compilation caches.
- Add unsigned cache-seed and isolated benchmark workflows, and strengthen build and workflow checks.

These changes target build reuse and cache management. Local and isolated hosted measurements demonstrate compiler reuse; they do not establish a universal build-time improvement.

## Distribution

The release follows the full client Quality gate and the coordinated tag workflow for signed/notarized macOS downloads and updater metadata, Linux APT and pacman packages, and internal iOS TestFlight promotion.
