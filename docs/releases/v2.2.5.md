# Synara 2.2.5

Synara 2.2.5 makes threads work on iOS, with the same thread display options as desktop.

## iOS threads

- Opening a thread loads its replies instead of showing only the first message. Earlier replies load on request, sent replies stay visible, and opening a thread no longer resets the room's timeline.
- Messages have Reply in Thread, which opens the thread with the composer ready.
- Settings → Appearance → Thread Display: Inline (the default) expands the latest replies beneath the first message, Sheet opens the thread over the room, and Full Screen opens it on its own screen.

## Distribution

The coordinated tag workflow validates the release and publishes signed/notarized macOS downloads and updater metadata, Linux APT and pacman packages, and the internal iOS TestFlight build.
