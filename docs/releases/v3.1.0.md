# Synara 3.1.0

Synara 3.1.0 makes the Linux app much cheaper to draw and smoother to type in, adds a Balanced drawing mode with an automatic fallback, and removes per-keystroke and per-edit work on every platform.

## Linux

- Hardware acceleration is now Off / Balanced / Full (Settings → Appearance → Window), and the Arch package starts in Balanced. Off, the previous default, drew every frame on the CPU and copied it on the thread that also handles typing: an animated "is typing…" indicator alone held about 30% of a core at 120 Hz. Balanced keeps GPU compositing and turns off only the DMABUF display path behind most NVIDIA blank-window reports. On an RTX 4080 SUPER under Hyprland, that thread dropped to about 10% with the indicator showing, and idles at under 1%.
- Automatic fallback: if the web view crashes in Balanced or Full, or a start in those modes ends before the window has drawn (for example NVIDIA's `Error 71`), Synara switches to Off, restarts, and explains it in Settings. Your saved choice is kept; choosing a mode tries again. `SYNARA_RENDERING` still decides when set.
- A web view that ends without a fallback (out of memory, or a crash in Off) is reloaded, at most three times in five minutes, instead of leaving a blank window.

## Desktop

- Continuous animations (typing dots, spinners, progress and connection bars) pause while the window is unfocused, and in Off mode step a few times a second instead of every frame. The message highlight pulses three times.
- Typing: the composer no longer stores the draft, converts it to Markdown and sends it to the core on every keystroke and cursor move. Drafts are written after a 0.4 s pause (at least every 2 s while typing), and at once on send, room or thread switch, window blur and quit.
- An edit to one message re-renders only that message; before, every visible message re-rendered on each edit, which added up while an agent updated a long progress message.
- While the side pane shows a thread, its expanded inline copy in the room stops streaming and shows its last replies until the pane closes.
- Diagnostics: Performance capture records typing latency (key press to next frame, p50/p95/max).

## All platforms

- Read receipts sent while a thread view closes no longer fail, and read-receipt errors report their actual cause.

## Known limits

- The crash fallback, the relaunch, and the stepped animations in Off mode were tested with unit and integration tests, not with a real WebKit crash or on KDE Plasma.
- Balanced was tried by hand on one NVIDIA/Hyprland system; the `.deb` and AppImage still start in Full until a mode is chosen.

## Distribution

The coordinated tag workflow validates the release and publishes signed and notarized macOS downloads and updater metadata, Linux APT and pacman packages, Windows installers, and the internal iOS TestFlight build.
