# Synara 2.1.20

Synara 2.1.20 completes the production current-device verification route and
refines cross-client message presentation without compromising readability or
accessibility.

## Device Verification

- “Verify This Device” now uses the Matrix Rust SDK's OwnIdentity request route
  instead of substituting a preferred peer device.
- Current-device status comes from the SDK's authoritative verification state;
  peer-row trust is no longer treated as proof that this device is cross-signed.
- Eligibility is explicitly true, false, or temporarily unknown, with matching
  enabled, unavailable, and retry presentation on iOS and desktop.
- Rust owns transitioned-SAS acceptance in both start directions and preserves
  `Confirmed` while waiting for the other participant.
- A repeatable live proof now requires an already cross-signed authority, a
  fresh unverified initiator, a nil-target OwnIdentity request, identical SAS,
  `Done`, authoritative `Verified`, and the same result after rebuilding the
  initiator's persisted crypto store.
- iOS proof assertions use an exact accessibility value, so `Unverified` can
  never satisfy the `Verified` completion check.

## Message Presentation

- Own and other iOS messages share the same leading reading column.
- A left-swipe timestamp automatically returns after 2.5 seconds and restarts
  cleanly when the gesture is repeated, without taking ownership from vertical
  room-history scrolling.
- Sender avatar URLs now cross the shared-core boundary for every timeline row;
  authenticated media loading and pending-message hydration preserve avatars
  through room changes and send retries.
- Delivery and retry controls remain adjacent to leading own-message content.

## Desktop Depth

- Resting messages remain on a flat reading plane.
- Selection, hover, avatars, and the composer use restrained depth only where it
  communicates interaction or hierarchy.
- Increase Contrast receives explicit non-text boundary tokens, and border
  transitions respect Reduce Motion.

## Validation

- The live OwnIdentity proof passed twice, including post-relaunch durable trust
  readback.
- Rust verification and device projection suites passed.
- Desktop modernization passed 837 tests, type checking, and production build.
- Focused iOS tests passed 86 cases and the final simulator build succeeded.
- Grok 4.6 High reviewed the implementation; every accepted finding was fixed
  and regression-tested before release.

## What to Test

- From a fresh iOS session, open Security & Recovery and verify the device from
  an already verified Synara or Element session. Confirm that both devices show
  the same SAS and that iOS remains Verified after relaunch.
- In a busy room, type while messages arrive, swipe a grouped message left, and
  confirm the timestamp returns automatically without harming vertical scroll.
- Confirm avatars appear for live, grouped, and locally pending messages.
- Compare desktop messages, room selection, avatars, and the composer in light,
  dark, Increase Contrast, and Reduce Motion modes.
