# Synara 2.1.40

Synara 2.1.40 tightens the native date rail, stops grouped-message hover from
shifting the row, restores Linux close-to-tray without a second copy, plays
macOS pings through NSSound, and pins Matrix Rust SDK 0.19.1.

## Timeline

- Date-rail ticks sit on the 2px spine. Live bottom selects the latest mark.
- Grouped-message hover timestamps fade in over the right gutter. The row does
  not move.

## Desktop shell

- Linux close-to-tray iconifies instead of unmapping, so GNOME keeps the
  running indicator and a launcher click restores this session. The tray
  paints a Slack-style unread count; Ubuntu Dock / Dash to Dock / KDE get the
  Unity launcher badge.
- macOS notification pings play through `NSSound` so they no longer appear as
  Now Playing media.

## SDK

- Desktop and shared Core pin matrix-sdk 0.19.1. The patch only ships the
  rustdoc Mermaid script docs.rs needs. Client APIs are unchanged.

## Validation

Desktop Package Smoke. iOS simulator unit and UI suites are skipped on
ordinary PRs and run on this `release/v2.1.40` candidate.

The maintainer authorized merging #1154 and cutting this release. Final
