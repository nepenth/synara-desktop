# Synara 2.1.43

Synara 2.1.43 consolidates the shared Matrix implementation in Rust and improves session recovery, notifications, and runtime reliability across desktop and iOS.

## Shared Matrix core

- Desktop and iOS share Rust ownership of session lifecycle, encryption recovery, notification policy, and timeline operations.
- Recovery and restore flows handle cancellation and account changes without letting stale work update the active session.
- Recovery keys and passphrases use typed boundaries and stay out of generic payloads and diagnostics.
- Four Rust packages use one workspace and lockfile. Supported dependency updates are consolidated, with remaining advisory and compatibility constraints documented.

## Desktop

- Remove obsolete Matrix JavaScript paths, IndexedDB deletion, unused call/PWA scaffolding, and superseded polyfills.
- Use native session wipe and fresh session generations as the source of truth for local reset.
- Retain the React and TypeScript interface with updated tooling and browser runtime coverage.

## iPhone and iPad

- Strengthen notification approval expiry, deduplication, account ownership, receipt handling, and notification extension isolation.
- Preserve composer text and timeline position while session and verification state changes.
- Validate generated async Rust/Swift bindings and the production notification extension archives.

## Release validation

The release PR must pass the full Quality gate, including iOS simulator unit and UI tests. The matching version tag starts exact-tag validation, signed and notarized macOS packages and updater metadata, Linux packages and repositories, and internal TestFlight delivery. Installed-package and physical-device checks remain recommended follow-up coverage under the release runbook.
