# Synara 3.1.1

Synara 3.1.1 fixes a composer crash when picking an emoji, shows what a file download is doing on desktop, and makes the iOS app icon count conversations instead of messages.

## Desktop

- Picking an emoji from the composer's emoji picker no longer replaces the screen with "Something went wrong … Cannot resolve a DOM node from Slate node". The picker refocused the message field before the new emoji was drawn; it now waits until it is.
- An emoji or mention inserted right at the end of a link goes after the link instead of becoming part of it.
- Downloading a file attachment shows its progress on the file: a percentage and a progress bar for a download that takes more than a moment, then "Finishing…". When it is done, a line under the file says "Saved to Downloads as …" with the name it was saved under and a Show in folder button. A failed download says why on the file, with Retry, instead of in the banner above the timeline. The media viewer's Save and the Markdown preview's Download show the same progress and result.
- Two downloads of the same file name at once no longer fail; the second is saved as "name (1)". A download only takes its name in Downloads once it is complete, so quitting mid-download no longer leaves a partial file.

## iOS

- The app icon counts conversations that need attention instead of unread messages. A room adds 1 when it has a mention, is marked unread, or has unread messages that notify you (DMs and rooms set to notify for all messages). Muted rooms, spaces and mentions-only rooms without a mention add nothing.
- Later adds 1 per reminder that is due, not per saved item.
- The app sets the icon itself while it runs instead of applying the push server's count. Notifications that arrive in the background add 1 per new conversation.
- Reading a room removes its delivered notifications from Notification Center.

## Known limits

- The emoji crash was reproduced and fixed in the test harness on Chromium and WebKit, not in the packaged macOS app; the macOS emoji panel was approximated in tests.
- Show in folder was not tried on Linux without a file manager service (it falls back to opening Downloads) or on Windows.
- On iOS, a push that carries only a count (sent when something is read on another device) still sets the icon to the server's number until Synara next runs; a count of zero clears it correctly. A reminder that comes due while the app is closed counts the next time the app runs. The background badge and notification removal were tested with unit tests, not on a device.

## Distribution

The coordinated tag workflow validates the release and publishes signed and notarized macOS downloads and updater metadata, Linux APT and pacman packages, Windows installers, and the internal iOS TestFlight build.
