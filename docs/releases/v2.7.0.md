# Synara 2.7.0

Synara 2.7.0 gives the desktop and iOS apps a calmer look that keeps Synara's style. It also shows who reacted to a message, makes links clickable again in formatted messages, and stops macOS updates from adding a second Dock icon.

## A calmer look (desktop and iOS)

- The dark theme's accent is blue, matching the light theme and the Synara mark.
- Messages, room rows and cards sit flat on the page. Raised surfaces are kept for things that float or still need you, such as unanswered approval requests.
- The Synara mark appears centred and larger on the sign-in screen, the empty room frame, About and the loading screen.
- Approval requests show the command once, with Approve once, Approve always and Deny as full-size buttons with plain icons instead of emoji. The reactions sent to the agent are unchanged.
- Desktop room rows are more compact, so more rooms fit on screen.
- Desktop text uses each platform's own font: San Francisco on macOS and Segoe UI Variable on Windows 11. On Linux, Synara ships Inter for Latin text. Code and Matrix IDs share one monospace font.

## Reactions

- Desktop: hovering a reaction shows who left it, for example "Alice, Bob and 3 others reacted with 👍". Right-click it for everyone, by name and Matrix ID.
- iOS: long-press a reaction, or choose View Reactions in the message menu.
- Screen readers name the people on each reaction.

## Fixes

- Desktop: web addresses in replies and formatted messages are clickable again. Since 2.3.0 only plain-text messages linked them.
- Desktop: a message sent right after someone's join or another room event now shows their name and avatar.
- macOS: updates keep the same Synara.app, so an icon pinned to the Dock stays pinned. The installed version performs the update, so this takes effect from the update after 2.7.0. You may need to re-pin once after installing 2.7.0.
- Windows: signing out and removing local data no longer fails while the database files are still closing.

## Distribution

The coordinated tag workflow validates the release and publishes signed and notarized macOS downloads and updater metadata, Linux APT and pacman packages, Windows installers (checked to launch to the sign-in screen first), and the internal iOS TestFlight build.
