# Synara 2.1.42

Synara 2.1.42 prepares the public desktop and iOS clients for release and improves the iOS conversation composer.

## iPhone and iPad

- Pasted multiline quotes and other Markdown formatting controls preserve the selected text and match the desktop composer more closely.
- The compact conversation composer sits above the home indicator, with the timeline using the available screen space.
- The connection recovery banner clears after 12 seconds even when sync reports repeated healthy updates.
- The iPad regular-width room list and timeline remain visible together.

## Desktop and public project

- README interface images show sample rooms from disposable accounts for macOS, iPhone, and iPad.
- The packaged desktop app loads its React interface through the Tauri window. Matrix media and local file handling received related readiness fixes.
- Public contribution, security, and support documentation is included.

## Validation and release gates

Feature PR #1160 passed its Quality gate and desktop package smoke. The release candidate must pass the full iOS simulator unit and UI suites, desktop package builds, and human package smoke before a version tag starts production publication and TestFlight delivery.
