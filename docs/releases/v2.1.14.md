# Synara 2.1.14

Synara 2.1.14 closes the complete native Matrix persistence boundary before
iOS suspension and repairs the desktop message-text appearance control.

## iOS Suspension Safety

- The submitted TestFlight crash was a `RUNNINGBOARD 0xdead10cc` termination:
  iOS suspended Synara while the Matrix event-cache SQLite store still held a
  write lock.
- Stopping `SyncService` alone was insufficient because the retained Matrix
  client stores and send queues remained open. The native lifecycle now stops
  sync, pauses the client, drains in-flight store work, and releases every
  SQLite connection before reporting that background quiescence is complete.
- Foreground activation performs the inverse transaction in the required order:
  resume the retained client stores, then restart the same `SyncService` owner.
- A native async mutex serializes the entire stop/pause/resume/start transaction
  for every FFI caller, including rapid foreground/background transitions.
- Quiescence now starts at `applicationWillResignActive`, while a bounded UIKit
  background assertion remains held until the complete native transaction
  finishes.

## Desktop Message Readability

- Appearance > Message text now changes both the native timeline and the
  compatibility renderer immediately.
- Bright is true white (`#ffffff`) in dark themes and true black (`#000000`) in
  light themes instead of a low-separation semantic-gray blend.
- Soft and Balanced remain visibly distinct from Bright, and every selectable
  foreground maintains at least 7:1 contrast on the supported message surfaces.
- Increased Contrast no longer overrides all three choices with one value.

## Validation

- A real SQLite-backed native regression proves that `stop_sync` returns only
  after the event-cache store is closed and that `start_sync` reopens it before
  restarting synchronization.
- Local validation passed the complete shared-core suite (789 passed, two
  ignored), all six P4-S12 lifecycle integration tests, and 21 focused iOS
  Matrix lifecycle tests with a rebuilt XCFramework.
- Desktop lint, type checking, production build, and all 827 modernization
  tests passed, including exact palette contrast and dual-renderer consumption
  tests.
- Hosted PR validation passed the full iOS simulator/device-release proof,
  Rust and Node validation, and macOS, Debian, and Arch package builds.
