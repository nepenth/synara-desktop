# Synara 2.1.7

Synara 2.1.7 is a coordinated macOS, Linux, and iOS reliability and readability
release. It repairs the complete Matrix device-verification operating path and
improves dense message and Settings layouts, with particular attention to Dark
Mode on Apple platforms.

## Device Verification

- The product sync service is now the single owner of verification events,
  removing the competing sync loop that could consume or reorder them.
- Starting SAS comparison delegates to the Matrix SDK on either side of the
  request instead of incorrectly limiting the action to one initiator.
- The UI represents key exchange as a real phase and retains the live SAS
  payload, so the seven emoji or decimal values can actually be presented.
- Verification targets the selected device, retains the active sheet while
  events arrive, and refreshes the trusted device snapshot after confirmation.
- iOS requires an explicit **Start Comparison** action and keeps the exact
  comparison values and confirmation actions readable in a scrollable sheet.

## Readability And Dark Mode

- iOS message text uses the platform body style instead of a smaller secondary
  style. Rich-message tables have distinct headers, semantic alternating row
  surfaces, separators, and horizontal scrolling for wide technical content.
- macOS message text uses a more comfortable line height and reading width,
  clearer paragraph and heading spacing, and bordered tables with alternating
  row backgrounds.
- iOS Settings reserves enough bottom clearance for the floating tab bar, so
  the final setting remains visible and tappable in Dark Mode.
- Room and event routes now use explicit component encoding, avoiding different
  behavior between macOS and Linux router implementations.

These choices follow Apple's guidance to use legible type and clear hierarchy,
semantic colors that adapt to appearance and contrast settings, alternating row
backgrounds for large macOS tables, and safe-area-aware layouts when navigation
bars float above content.

## Validation

- Two live iOS simulators completed request, acceptance, explicit SAS start,
  the same seven emoji, confirmation on both sides, and verified trust readback.
- Dark Mode geometry checks confirmed that the final Settings row clears the
  floating tab bar.
- The product PR passed 521 iOS unit tests, 52 iOS UI tests, 768 shared Rust
  tests, 442 desktop Rust tests, 808 desktop modernization tests, real Chromium
  layout tests, performance checks, and macOS/Linux package smoke gates.
- No test Matrix passwords, access tokens, device identifiers, or SAS values
  are included in this release.

## Upgrade Notes

- Existing sessions and crypto stores should restore normally.
- macOS updates through the Tauri updater. Linux updates through the pacman
  repository or `.deb`. iOS updates through TestFlight.
