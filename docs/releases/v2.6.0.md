# Synara 2.6.0

Synara 2.6.0 is a maintenance release. It makes the desktop app build and test on Windows, completes the iOS privacy manifests, and fixes a flaky test. Nothing changes in how the macOS, Linux or iOS apps behave.

## Windows (not released)

- The desktop app builds on Windows and passes its Rust and renderer tests there. It stores secrets in Windows Credential Manager, shows an unread dot on the taskbar button, and loads its media under Windows' `http://tauri.localhost` origin.
- `.github/workflows/windows-spike.yml` checks this weekly and on demand, and on demand also builds an unsigned MSI and NSIS installer for testing.
- Windows isn't a published platform yet: no signed builds, updater, toasts or deep links. `docs/windows-support-spike.md` lists what is left.

## iOS

- The app's privacy manifest declares the required-reason APIs it uses: UserDefaults, system boot time and file timestamps. The notification service has its own manifest. Synara still tracks nothing and collects no data.

## Maintenance

- A Rust runtime test no longer fails at random.
- Stale branches, stashes and worktrees were removed after checking that their work is on main or was superseded.

## Distribution

The coordinated tag workflow validates the release and publishes signed/notarized macOS downloads and updater metadata, Linux APT and pacman packages, and the internal iOS TestFlight build.
