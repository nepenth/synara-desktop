# Synara 2.6.0

Synara 2.6.0 fixes signing in through a proxy server address, adds Windows installers, completes the iOS privacy manifests, and fixes a flaky test.

## Sign-in (desktop and iOS)

- Signing in with a plain username works when the server address is a proxy whose name differs from the homeserver's own name, such as an IPv4 proxy `matrix-v4.example.org` in front of `matrix.example.org`. Synara used to turn `pete` into `@pete:matrix-v4.example.org`, which the server rejects. It now sends the username as typed, as Element does, and keeps the Matrix ID the server returns.
- On desktop, a full Matrix ID whose server can't be reached (for example an IPv6-only server from an IPv4 network) signs in through the server chosen on the sign-in screen instead of failing with "Failed to find your Matrix ID server."

## Windows (new)

- Download `Synara_2.6.0_x64_en-US.msi` or `Synara_2.6.0_x64-setup.exe` from this release (Windows 10 or 11, x64).
- The installers aren't code-signed yet, so SmartScreen warns the first time: choose "More info", then "Run anyway".
- Secrets are kept in Windows Credential Manager, and the taskbar button shows a dot for unread messages.
- Not yet on Windows: a built-in updater (install the next release over this one), notification action buttons, and deep links. `docs/windows-support-spike.md` lists what is left.

## iOS

- The app's privacy manifest declares the required-reason APIs it uses: UserDefaults, system boot time and file timestamps. The notification service has its own manifest. Synara still tracks nothing and collects no data.

## Maintenance

- pulldown-cmark is updated to 0.13.5 for RUSTSEC-2026-0414.
- A Rust runtime test no longer fails at random.
- Stale branches, stashes and worktrees were removed after checking that their work is on main or was superseded.

## Distribution

The coordinated tag workflow validates the release and publishes signed/notarized macOS downloads and updater metadata, Linux APT and pacman packages, unsigned Windows installers, and the internal iOS TestFlight build.
