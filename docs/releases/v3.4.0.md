# Synara 3.4.0

Synara 3.4.0 adds a keyboard quick edit on desktop, makes draft sync work on every verified device, and adds a Restart now button to the Linux Hardware acceleration setting.

## Quick edit from the keyboard (desktop)

- With the message box empty, press Up to select your last message in that room, then E to edit it in place. Saving or cancelling the edit puts you back in the message box.
- While a message is selected, Up and Down move between messages, and Escape (or Down from the newest message) returns to the message box.
- E edits only your own text messages. A thread pane's message box selects your last reply in that thread.
- With a draft in the box, Up moves the caret as before. If your newest message is still being sent, Up waits for it rather than selecting an older one.
- A message that has focus is announced to screen readers by its sender and text. Both keys are in the keyboard shortcut list (Cmd/Ctrl+/).

## Draft sync on every verified device (desktop and iOS)

- Sync drafts across devices now works on every verified device, without the recovery key. Before, the key that encrypts synced drafts was created only when a device set up recovery or entered the recovery key, so an account whose devices were all verified by emoji or QR code never synced drafts.
- A verified device asks your other verified devices for the key and creates it after a few seconds if none has it. Devices that each created one settle on the same key.
- Every device needs this version. The hint under the setting (Settings › Messages) says when a device is not verified, and updates by itself once sync starts.

## Linux

- The Hardware acceleration setting (Settings › Appearance › Window) shows a Restart now button once you change the mode. Closing the window leaves Synara running in the tray, so a new mode did not apply until you quit from the tray icon; the note under the setting now says so.
- On a large or high-refresh display, Balanced mode copies every frame on the CPU on the thread that also receives typing, which can delay keystrokes. If typing lags, try Full. Synara returns to CPU drawing by itself if the display crashes or the window never draws.

## Known limits

- Quick edit was tested in browser harnesses (Chromium and WebKit), not in the packaged apps against a live homeserver.
- Restart now was compiled and unit-tested on Linux but not clicked in a packaged build.
- Draft sync between verified devices was not tested between two real devices by this release's checks.
- The typing-delay advice comes from one machine (NVIDIA RTX 4080 SUPER, 3440×1440 at 120 Hz, Hyprland). Balanced stays the Arch package's default.
- The iOS app is still built with the iOS 26 SDK; the move to the iOS 27 SDK is ready but waits for GitHub's Xcode 27 runner image to leave preview.

## Distribution

The coordinated tag workflow validates the release and publishes signed and notarized macOS downloads and updater metadata, Linux APT and pacman packages, Windows installers, and the internal iOS TestFlight build.
