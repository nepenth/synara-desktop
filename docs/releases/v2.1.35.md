# Synara 2.1.35

Synara 2.1.35 restores room member moderation, timeline copy/selection, Linux
sleep sync recovery, unread badges, and agent-approval alerts.

## Room member options

- Desktop and iOS member profiles use native membership snapshots instead of
  `room.getMember()`, so Kick, Ban, Unban, Invite, knock accept/deny, and
  power-level writes appear for joined members.
- Writes stay hidden until the native member list is ready. A failed snapshot
  shows an error instead of offering moderation.
- Cancel Invite stays on the invite alert.

## Copy, paste, and composer

- Copy All writes sanitized HTML. iOS Select Text selects a substring in a
  non-editable text view. Desktop Copy Message writes plain text and HTML.
- The composer prefers HTML paste and converts attributed text to markdown, so
  markup characters are not shown in the compose box.
- Bold wrapping compares each run to the composer base font so Accessibility
  Bold Text does not send every typed message as `**text**`.

## Sleep, unread, and approvals

- After desktop sleep, `SyncIntent::Resume` restarts a live owner when the SDK
  still reports Running on a dead long-poll. A short hide no longer leaves a
  stale hide stamp that could recover on a later focus.
- Sliding-sync subscriptions cover every joined room so encrypted rooms get
  client-side unread math. iOS room-list snapshots pulse after decrypt and
  receipts.
- Pending last-message approval prompts bump mention/unread only while SDK
  unread counters are still non-zero. Receipts that zero those counts clear
  badges even if the latest event is still the prompt.
- Encrypted observations retry after decrypt. iOS Time Sensitive agent
  approvals default on.
- Desktop tray approval counts use Core's raw last-message classifier, not the
  collapsed preview.
- Native timeline message bodies use the available column width instead of a
  672px cap.

## Validation

#1119, #1120, and #1121 merged to `main` after their required Quality gates.
#1121 also passed macOS, Debian, and (when complete) Arch package builds. iOS
simulator unit and UI suites are skipped on ordinary PRs and run on this
release candidate.

The maintainer authorized merging those fixes and cutting this release. Physical
device Bold Text, final signed-artifact install/update, and live cross-client
UI checks were not repeated here.

On-device smoke still worth doing before tagging: Settings → Accessibility →
Bold Text, type `hello` in the composer, and confirm the sent body is `hello`
rather than `**hello**`.
