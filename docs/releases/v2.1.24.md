# Synara 2.1.24

Synara 2.1.24 makes formatted Matrix messages easier to scan and more faithful
across iOS, macOS, and Linux while preserving accessible contrast, selection,
copying, and spoiler concealment.

## Semantic Rich Text

- Bold and emphasized text now has a clearer but restrained hierarchy.
- Inline code, code blocks, tables, headings, quotes, and spoilers use dedicated
  semantic presentation roles instead of relying on generic message colors.
- Native desktop rendering, compatibility HTML, Prism syntax highlighting, and
  iOS attributed text share the same presentation intent.

## Theme And Contrast

- Light, dark, Silver, Butter, and custom themes derive rich-text surfaces from
  their actual message-reading canvases.
- Matrix-authored foreground and background colors remain part of the message,
  but their displayed colors are clamped when needed to reach WCAG 4.5:1 text
  contrast, or 7:1 with Increased Contrast enabled.
- Nested colors resolve against the surface actually painted behind their
  glyphs, including tables, code, message bubbles, and revealed spoilers.
- Desktop color context is cached per theme revision and refreshed when the
  theme or operating-system contrast preference changes.

## iOS Reading And Copying

- Rich text respects Dynamic Type and the actual incoming or outgoing message
  bubble surface.
- Inline code is easier to identify without adding a visually heavy boundary;
  Increased Contrast adds a stronger verified edge.
- Selection and formatted copy retain safe message structure without exposing
  concealed spoiler text.

## Spoilers And Compatibility

- Concealed spoiler descendants are not mounted into the interactive desktop
  interface until the user reveals them, preventing hidden links or controls
  from entering keyboard navigation.
- Pointer and Enter/Space reveal paths now share one state-owned implementation
  across compatibility surfaces.
- Legacy Matrix `font` colors are normalized to the same strict, sanitized
  authored-color representation used by current messages.

## Validation

- Desktop typecheck, lint, formatting, production build, and all 891
  modernization tests passed.
- The protected PR Quality gate passed its complete iOS simulator and clean
  device-Release proof.
- macOS, Debian, and Arch package-smoke builds passed.
- Independent implementation and acceptance reviews completed without
  remaining findings.
- Grok 4.6 High identified a native spoiler paint-order issue; it was corrected,
  independently approved, and returned `FIX_VERIFIED` on the immutable commit.

## What To Test

- Compare bold, inline code, tables, code blocks, and spoilers in light and dark
  modes across iOS, macOS, and Linux.
- Toggle Increased Contrast and confirm formatted regions become clearer without
  changing message structure or copied text.
- Exercise Silver, Butter, and a custom theme, including hover states on tables
  and spoiler reveal.
- Select and copy formatted messages, including nested authored colors, and
  confirm concealed spoilers remain absent until explicitly revealed.
