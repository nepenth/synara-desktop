# Synara 2.1.31

Synara 2.1.31 is a client fix release for the 2.1.30 line: last-read
navigation that works on both platforms, a Devices settings page that loads,
a calmer and reorganized desktop Settings window, and iOS account and
re-login fixes.

## Reading And Navigation

- Desktop Jump to Last Read no longer fails with "The last-read message is not
  available in this context". Core resolves a marker that has no row of its
  own (reaction, edit, redaction, hidden event) to the nearest rendered
  predecessor when opening a focused window, and the renderer adopts that
  anchor.
- On both desktop and iOS the control sits in the bottom-right cluster beside
  Jump to latest as a matching pill. It appears only while the room had unread
  and the last-read frontier is not yet placed; it is retired on placement, on
  an explicit Jump to latest, or when the room changes. Receipt state is not
  consulted, so the live-tail auto receipt cannot hide it before the gap has
  been seen.
- A single wheel step away from the desktop live tail now stays put. Scroll
  listeners are bound once per mounted viewport instead of per render, which
  had raced the virtualizer and dropped the first scroll event of a gesture.

## Devices And Verification

- Desktop Settings > Devices loads whenever a session is present. The query
  was gated on a session-generation marker the desktop store never populates,
  which left Device Verification spinning, Retry inert, Encryption Backup
  reading Disconnected, and the Current device list empty.
- A rejected snapshot renders a retryable "Device list unavailable" card
  instead of a false "could not check eligible verified sessions" prompt.
  Current-device verification is offered only from a loaded snapshot.

## Desktop Settings

- Settings cards no longer carry the gradient fold and inner edge; resting
  surfaces match the room, space, and common settings elsewhere in the app.
- Theme, monochrome mode, base and accent colors, message text, page zoom, and
  message layout move to a dedicated Appearance page.
- General gains a Storage group (native session store status and Clear Cache
  & Reload). Update checking lives once under General > Software Updates and
  the duplicate Options block is removed from About. Media loading is phrased
  positively ("Load Media Automatically") and tiles gain descriptions.

## iOS

- The Account sheet resolves the live app environment. It previously read
  "Not signed in" and its Settings and Log Out actions targeted a router
  nobody observed.
- Log Out followed by Log In on the same device starts the Matrix client
  again. The signed-in readiness gate still remembered the reused
  `user|device` identity as prepared, so `matrix.start` was skipped and the
  room list stayed empty until a force-quit.

## Validation

Local checks passed 965 renderer tests, 46 Playwright timeline e2e cases
(including a new single-wheel-step regression), Core fmt/clippy/tests with the
new focused-open resolution test, and the iOS unit and UI suites (readiness
reset, re-login, last-read policy, and account sheet coverage). The feature
pull request ran the CI Quality gate before merge; the release branch reruns
Quality gate with both iOS simulator suites and Desktop Package Smoke.

Candidate install smoke on the packaged desktop artifacts and a TestFlight
build remains to be recorded in `docs/production-smoke-checklist.md` before
the `v2.1.31` tag is pushed.
