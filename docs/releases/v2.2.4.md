# Synara 2.2.4

Synara 2.2.4 polishes the redesigned sign-in screen.

## Sign-in

- The Synara mark is centered over the name, and the "y" in Synara is no longer clipped.
- The background grid is now still; the moving grid looked like a display glitch.

## Distribution

The coordinated tag workflow validates the release and publishes signed/notarized macOS downloads and updater metadata, Linux APT and pacman packages, and the internal iOS TestFlight build.
