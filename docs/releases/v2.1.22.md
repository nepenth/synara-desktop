# Synara 2.1.22

Synara 2.1.22 makes desktop interaction depth more coherent while protecting
the primary reading and text-selection paths on macOS and Linux.

## Composer Alignment

- The add button, editor, text options, emoji action, and send button now share
  an explicit vertical center within the message composer.
- Optical corrections are applied at the control level instead of shifting the
  whole bar, preserving focus rings, hit targets, and keyboard behavior.

## Room Navigation

- Resting room rows no longer draw persistent horizontal separators.
- Hover and selected states retain restrained elevation, surface contrast, and
  a clear leading selection indicator.
- Create Room, Join with Address, and Message Search now use the same quiet
  interaction-depth treatment as other navigation controls.

## Personal Notes

- Note and ToDo tabs have complete, unclipped shapes and consistent hit areas.
- The editor, add action, empty state, and saved rows share the restrained
  surface, edge, hover, and pressed hierarchy used elsewhere in the app.
- Increased-contrast, reduced-motion, and forced-color modes retain clear
  boundaries without depending on shadows alone.

## Message Interaction

- A primary-button mouse drag remains owned by native text selection and can no
  longer reveal a message timestamp.
- On macOS, horizontal trackpad intent reveals the timestamp without requiring
  a click-drag gesture.
- Touch and pen pointer paths retain deliberate horizontal reveal behavior for
  Linux devices that support those inputs.
- Direction locking and editable/interactive target guards keep vertical room
  history scrolling and message controls responsive.

## Room Header Controls

- Search, pinned messages, notes, members, and overflow actions now share the
  same restrained hover and pressed dimensionality as the rest of the desktop
  interface.
- Focus-visible, increased-contrast, reduced-motion, and forced-color behavior
  remain explicit.

## Validation

- TypeScript type checking, ESLint, Prettier, and 847 modernization tests
  passed locally.
- Six focused Playwright timeline interaction tests passed, including mouse
  text-selection ownership and trackpad timestamp reveal.
- Production Vite build and diff validation passed.
- CI passed its renderer quality gate and built a signed macOS app bundle,
  Linux `.deb`, and Arch package.
- Grok 4.6 High reviewed the implementation; its blocking concerns were
  addressed before the final review reported no remaining blockers.

## What to Test

- Compose a message on macOS and Linux and confirm every control appears
  vertically centered at rest, on hover, and while focused.
- Select text in an existing message with a mouse drag and confirm the message
  does not move; use a two-finger horizontal trackpad gesture to reveal time.
- Review resting, hovered, and selected rooms and confirm separators appear
  only through meaningful interaction hierarchy, not between every row.
- Open Personal Notes at narrow and wide panel widths and confirm its tabs,
  editor, add action, empty state, and saved rows remain unclipped and coherent.
- Exercise room-header and Home actions with pointer and keyboard navigation in
  standard, increased-contrast, and reduced-motion configurations.
