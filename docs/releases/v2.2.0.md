# Synara 2.2.0

Synara 2.2.0 fixes session drops that did not recover, Mark as Read that did not clear other clients, the immovable Linux window and unsent messages that looked sent. It also moves the remaining client logic into the shared Rust core used by desktop and iOS.

## Sessions and sync

- A session the homeserver rejects now retires locally on both desktop and iOS, without another remote logout and without deleting encrypted history. Signing out finishes even when the homeserver does not answer.
- The connection banner shows Connection Lost when commands cannot run, and shows Reconnecting until sync actually responds.
- Sync restarts immediately after an expired sliding-sync session and re-applies the open room's subscription, so timelines no longer go gappy after sleep.
- Logout gives pending room keys a moment to reach the key backup and warns when this is the account's last signed-in device.

## Messages and Mark as Read

- Mark as Read targets the newest message, including thread replies, so the room clears on your other clients.
- Messages that have not reached the server show as sending or failed, with Discard and Retry. A send the SDK still holds stays visibly queued and resends when sync recovers.
- Reactions work in thread and permalink views, and redactions stay ordered with queued edits.

## Encryption

- Messages show an authenticity shield when the sender's device or identity is not trusted, and a banner warns when a room member's identity changes.
- Verifying with a QR code now asks you to confirm the other device reported success.
- History now comes from the encrypted key backup instead of unauthenticated forwarded keys, and backup setup always shows the recovery key.

## Desktop

- Linux: closing the window hides Synara to the tray, like macOS. The window drags from the title strip on Wayland and stays without a native title bar after relaunch.
- Space order and pins, recent emoji and Developer Tools account data persist again. Mutual rooms, local room addresses, alias checks, room upgrade and `/delete` work natively.
- The room list refreshes on change instead of polling, media and avatars load from a cache as thumbnails, and background polling slows while the window is hidden.

## iOS

- Encryption shields, identity-change warnings, shared room ordering and badge totals, and the same session retirement and logout behaviour as desktop.
- Status values from Core are typed, so unknown values can no longer appear as raw text.

## Distribution

The coordinated tag workflow validates the release and publishes signed/notarized macOS downloads and updater metadata, Linux APT and pacman packages, and the internal iOS TestFlight build.

For iOS notification previews to keep working between app launches, set Synapse `refreshable_access_token_lifetime` to a longer value (for example `7d`).
