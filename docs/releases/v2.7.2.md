# Synara 2.7.2

Synara 2.7.2 brings link previews to iOS and hardens them on desktop.

## iOS

- Link previews: the first link in a message shows a card with the site, the page's title and description, and its image, in encrypted rooms too. The iPhone fetches the page itself with the same protected code as desktop, which never reaches your local network. Turn previews off in Settings → GIFs & Link Previews → "Link Previews".

## Desktop

- Preview cards name the link's real host first, followed by the page's own site name, so a page can't pass itself off as another site.
- Previews refuse local network names (`localhost`, `.local`, `.lan`, `.internal`, `.home.arpa` and single-word names) before looking them up, including after redirects.

## Distribution

The coordinated tag workflow validates the release and publishes signed and notarized macOS downloads and updater metadata, Linux APT and pacman packages, Windows installers (checked to launch to the sign-in screen first), and the internal iOS TestFlight build.
