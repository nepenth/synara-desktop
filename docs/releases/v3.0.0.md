# Synara 3.0.0

Synara 3.0.0 replaces the desktop's left rail with a bar at the bottom of the room list and a space switcher, adds a tiling mode for Linux window managers such as Hyprland, makes the app usable in narrow windows and from the keyboard, and introduces a simpler Synara mark on every platform.

## Desktop

- Navigation: Home, Activity, Approvals and your account menu sit in a bar at the bottom of the room list. Spaces are in a switcher on the list's title (Ctrl/Cmd+Shift+S) with search, folders, drag to reorder and Manage spaces.
- Narrow windows: the minimum size is 360×480, layouts work from 380px up, and side panels open as overlays below desktop width.
- Keyboard: a shortcut help sheet (Ctrl/Cmd+/), Alt+1–4 (⌃1–4 on macOS) for Home, Activity, Approvals and Settings, F6 to move between panes, and optional Vim-style list keys.
- Notifications (Linux, macOS): Mark as read and Reply on message notifications. On macOS you type the reply in the notification; on Linux Reply opens the room with the composer focused.
- `synara://` links open rooms, events and places in the running app.
- `synara status` prints your counts as text, JSON or a Waybar module.
- Appearance: Follow system theme colors (the Omarchy theme on Linux, the system accent on macOS), and interface and monospace font settings.
- Fixes: rooms with room version 12 IDs open again, and a local homeserver typed with `http://` connects at sign-in.

## Linux

- Tiling mode: under Hyprland, Sway, Niri, i3 and similar, Synara drops its own title strip and leaves window size and position to the compositor. Settings → Appearance → Window has Auto, On and Off.
- Hardware acceleration: a switch in Settings → Appearance → Window, applied on the next start. It is off by default in the Arch package. If the window flickers, goes blank or the app closes at start, turn it off, or start once with `SYNARA_RENDERING=safe synara`.
- The window class is `synara`; `docs/linux.md` has example window rules.

## iOS and iPad

- New app icon and in-app mark.

## Known limits

- Hardware acceleration was checked on Hyprland with an NVIDIA card; other compositors and drivers are untested.
- Notification actions and the macOS accent color were not exercised in a packaged build before this release.
- Windows: `synara://` registration is new and untested on hardware; notification actions are not available.

## Distribution

The coordinated tag workflow validates the release and publishes signed and notarized macOS downloads and updater metadata, Linux APT and pacman packages, Windows installers (checked to launch to the sign-in screen first), and the internal iOS TestFlight build.
