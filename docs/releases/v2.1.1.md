# Synara 2.1.1

Synara 2.1.1 is a coordinated macOS, Linux, and iOS fix release. It restores
desktop login against leftover crypto stores, places unread rooms at the last
read receipt instead of a stale fully-read marker, and brings the desktop room
list and timeline closer to Element-style presentation.

## Desktop Login

- Password login reuses a leftover local crypto device instead of failing with
  an Olm-unavailable error after an interrupted previous session.
- macOS and Linux share this path; both are the same Tauri shell.

## Last-Read And Timeline Placement

- Opening an unread room stays on the live timeline and places at the newest
  comparable public or private receipt, not a stale `m.fully_read` marker.
- Automatic edge pagination no longer crawls history on every snapshot.
- Jump to latest follows the live tail even when the room is already in live
  mode, instead of no-oping when the placement key does not change.

## Room List And Message Presentation

- Room chips use two-letter initials and a muted dark-theme palette instead of
  hash icons or pastel username-color fills.
- Message rows show sender avatars, display names, timestamps, and body cards,
  group consecutive sends, and render formatted HTML without pre-wrap.
- Hover and focus still expose reaction and more-actions controls.

## iOS And TestFlight

- Shared last-read placement applies through native core. iOS keeps its own
  list and message UI.
- TestFlight promotion publishes versioned notes for this exact build.

## Upgrade Notes

- Existing native sessions should restore normally. If a previous login left a
  leftover crypto store, the next password login should succeed without wiping
  the device.
- macOS updates through the Tauri updater. Linux updates through the pacman
  repo or the `.deb`. iOS updates through TestFlight.

## Validation

The release is gated by renderer lint and type checking, modernization tests,
Rust workspace and desktop-shell tests, dependency audits, iOS simulator tests,
macOS bundle validation, Linux Debian and Arch package validation, and live
disposable-homeserver Matrix proofs.
