# Synara 2.9.2

Synara 2.9.2 moves slash commands into the shared core so desktop and iOS offer the same commands, turns a typed @name into a real mention, closes approval alerts on their own once you decide elsewhere, and opens mentioned people inside Synara on iOS.

## Desktop

- Slash commands: every command is checked and run by Synara's core. New are /topic, /roomname, /nick, /myavatar, /op, /deop, /msg, /query, /whois, /upgraderoom, /jumptodate, /spoiler, /plain, /html, /lenny and /help, with /j, /goto and /part as shortcuts. Suggestions show how to use each command and only list the ones you have permission for; /ban, /delete and /upgraderoom ask before they run.
- Mentions: typing @Name without picking from the list now sends a real mention when exactly one person in the room matches.
- Approvals: an approval alert closes itself once the request is decided on any device, settled by the agent, removed or expired, even with Synara closed to the tray.

## iOS and iPad

- Slash commands, the same as on desktop: type / for suggestions with usage hints, and confirm before destructive commands.
- Mentions: tapping a mention opens that person's member sheet in Synara instead of Safari, and a typed @Name becomes a real mention when it matches one person.

## Distribution

The coordinated tag workflow validates the release and publishes signed and notarized macOS downloads and updater metadata, Linux APT and pacman packages, Windows installers (checked to launch to the sign-in screen first), and the internal iOS TestFlight build.
