# Synara 3.5.0

Synara 3.5.0 lets you open a person's profile from any message they sent, and start a direct message with them from there, on desktop and iOS.

## Profile from a message's sender (desktop)

- Click the sender of a message, the name or the picture, to open that person's profile. It is the popover the member list and mentions already open, with Message, Mention, Copy user ID, Ignore and the moderation actions you are allowed to use.
- The name is the control for the keyboard and screen readers; the picture is a pointer target for the same profile. Grouped follow-on messages have no header and so no control.
- This works in rooms and in threads.

## Message creates the chat (desktop)

- Message on a profile opens your direct message with that person. When there is none, it creates an encrypted one and opens it. It used to send you to the new-chat form, with the person's ID filled in, to press Create.
- While the chat is being created the button shows progress and cannot be pressed again, and a second request for the same person shares the first, so one chat is made. If it fails, a short error shows under the button and you can try again.
- The new-chat form stays for starting a chat from a typed user ID.

## Member sheet from a message's sender (iOS)

- Tap the sender of a message, the name or the picture, to open the member sheet that mentions and the member list open.
- Send message on that sheet used to create a new direct message every time and leave you on the sheet. It now opens your existing direct message with that person (the most recently active one, as on desktop), creates one only when there is none, and takes you to it.

## Dependencies

- `url` 2.5.9, which fixes a stack overflow in `Url::origin()` on nested `blob:` URLs (RUSTSEC-2026-0592, published 2026-11-20).

## Known limits

- The desktop changes were checked with unit tests and the timeline browser suite, which records which profile a click asks for. The profile popover and its Message button were not exercised by hand in a browser or in the packaged app.
- The iOS changes were checked with unit tests and a UI test in the simulator, not on a phone.
- On iOS, a sender who is no longer in the room shows "Not a member of this room." with no actions.
- There is no action to verify another person from the profile; the core has no such operation yet.
- The iOS app is still built with the iOS 26 SDK.
