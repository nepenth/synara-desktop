# Synara 2.1.46

Synara 2.1.46 addresses rejected-session connection loops, improves refresh-token persistence, and corrects iOS encryption guidance and conversation layout.

## Connection and session recovery

- Stop retrying credentials that the homeserver has rejected. Desktop returns to sign-in with an expired-session explanation instead of presenting authentication failure as a server outage.
- Keep the homeserver capability probe anonymous and retain bounded recovery for temporary network failures.
- Track failed refresh-token saves, retry the local credential write while the session remains active, and show a warning when storage is unavailable.
- Preserve encrypted local history when retiring a rejected session, and record bounded session-lifecycle diagnostics without tokens or private message data.

A token already rejected by the server requires signing in again. This release cannot revive that token. The original incident's exact credential-storage failure remains unconfirmed; the investigation and reproduced SDK save-failure behavior are documented in the repository review.

## iOS encryption and interface

- Show device verification guidance separately from actual undecryptable messages. Room recovery controls now follow the SDK's observed encrypted placeholders, and Security avoids an unmeasured all-clear count.
- Connect Retry Decryption to the existing Core-owned live timeline. Recovered keys update readable messages without reopening the timeline or replacing the device identity.
- Update the Support email to synara-support@whyland.com.
- Reduce the gap above Favorites and the room list, and join the message composer background to the native keyboard.

## Dependencies

- Integrate the reviewed renderer dependency updates and patch Seroval and source-map-js advisories.

## Distribution

The coordinated tag workflow validates the release and publishes signed/notarized macOS downloads and updater metadata, Linux APT and pacman packages, and the internal iOS TestFlight build.
