# Synara 3.4.1

Synara 3.4.1 has no app changes. It exists so the iOS build can also go to external TestFlight testers: a build uploaded for internal testing only, as 3.4.0 was, can never be moved to an external group.

## Release pipeline

- The release workflow can publish the iOS build to external TestFlight groups. A new job, `ios-testflight-external`, submits the processed build for Apple's beta review and assigns it to the groups in the repository variable `SYNARA_TESTFLIGHT_EXTERNAL_GROUP_IDS`. It runs after the internal gate and does not wait for the review; testers get the build when Apple approves it.
- External groups need `SYNARA_TESTFLIGHT_INTERNAL_ONLY` set to `false`. The upload job fails before archiving if external groups are set while internal-only is still on.
- The TestFlight promotion recovery workflow runs the same external step.

## Known limits

- The external step was tested against a fake App Store Connect client only. This release is its first run against Apple.
- Apple refuses a beta review submission until the app's TestFlight Test Information (beta description, feedback email, review contact, sign-in details) is filled in on App Store Connect. If the job fails for that reason, fill it in and re-run that job.
- The known limits of 3.4.0 still apply.

## Distribution

The coordinated tag workflow validates the release and publishes signed and notarized macOS downloads and updater metadata, Linux APT and pacman packages, Windows installers, and the iOS TestFlight build for the internal group and the external Friends group.
