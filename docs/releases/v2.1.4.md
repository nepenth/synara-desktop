# Synara 2.1.4

Synara 2.1.4 is a coordinated macOS, Linux, and iOS product release. It
makes failed and offline iOS sends recoverable, adds long-press copy and
edit for unsent messages, holds connection-lost chrome through short
blips, and fixes desktop unread receipts plus timeline layout.

## iOS Sending

- Failed text sends retry from a chip on the bubble, not a full-row
  button that swallowed Retry and Copy.
- Offline text is queued in the session and flushed when sync is
  connected or running. Queued rows stay visible while the timeline is
  loading.
- Failed local echoes can be edited in the composer and retried on the
  same pending id. Remote edits still use `m.replace`.
- Long-press Copy copies the plain body. Text selection is a best-effort
  substring path.

## iOS Connection

- Connection Lost waits through 1–5s SDK Offline blips. Steady Connected
  stays hidden; Connected only flashes after a Lost banner the user saw.
- Empty-state copy follows that held chrome, not the live SDK string.

## Desktop Timeline

- Message rows use a full-width slightly-off-color surface instead of a
  body-only chip.
- The typing bar sits in the layout flow so it shifts the last message
  up instead of covering it.
- Unread badges and Mark as Read go through native receipts
  (`matrix_room_set_read_state`). Stale mark-read readbacks do not error
  the timeline.

## Upgrade Notes

- Existing native sessions should restore normally.
- macOS updates through the Tauri updater. Linux updates through the
  pacman repo or the `.deb`. iOS updates through TestFlight.

## Validation

The release is gated by renderer lint and type checking, modernization
tests, Rust workspace and desktop-shell tests, iOS simulator tests, macOS
bundle validation, and Linux Debian and Arch package validation.
Version-only bumps reuse a proven Quality gate on the tagged SHA.
