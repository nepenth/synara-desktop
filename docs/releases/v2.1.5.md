# Synara 2.1.5

Synara 2.1.5 is a coordinated macOS, Linux, and iOS product release. It
stops device-verification Settings from hanging on a spinner, reuses the
same Matrix device after iOS sign-out, and lets clients list and force
sign-out other sessions.

## Device Verification

- Settings → Devices no longer holds the auth mutex across `/keys/query`.
  Local identity is read first; the homeserver fetch is bounded to 8s.
  If private keys are complete but identity is missing, the page shows
  Unverified and Verify This Device instead of spinning forever.
- Linux uses the same Tauri binary as macOS.
- iOS Core identity lookup and Verify This Device use the same bounded
  helper, so Security cannot stall on the same keys query.

## Sessions

- iOS logout no longer wipes the per-account crypto store. The next
  password login reuses the stored device id instead of creating a new
  Matrix session on every sign-in.
- iOS Account → Sessions lists devices with trust, last activity, and
  device id. Other sessions can be signed out with the account password.
- Desktop Settings → Devices → Others already listed sessions and could
  force logout with password UIAA or the OIDC dashboard.

## Upgrade Notes

- Existing native sessions should restore normally.
- Signing out of iOS and signing back in should keep the same Device id
  unless the store is reset (`SYNARA_RESET_SESSION_ON_LAUNCH`).
- macOS updates through the Tauri updater. Linux updates through the
  pacman repo or the `.deb`. iOS updates through TestFlight.

## Validation

The release is gated by renderer lint and type checking, modernization
tests, Rust workspace and desktop-shell tests, iOS simulator tests, macOS
bundle validation, and Linux Debian and Arch package validation.
Version-only bumps reuse a proven Quality gate on the tagged SHA.
