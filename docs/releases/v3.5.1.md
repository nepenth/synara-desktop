# Synara 3.5.1

Synara 3.5.1 shortens the time over which consecutive messages from one person are shown as a single group, on desktop and iOS.

## Message grouping (desktop and iOS)

- Consecutive messages from one person share one name, picture and time. A message now joins the group only when it was sent less than 5 minutes after that person's previous message. The limit was two hours.
- Before, someone who wrote now and then through a morning appeared under the time of their first message, and separate topics read as one long message.
- The gap is measured from when the previous message was first sent. Editing a message does not change its time, so a message that an agent keeps editing stays one message with its original time. A new message sent 5 minutes or more after that original time starts a new group, even when the last edit was a moment ago.
- The other rules are unchanged: a different sender, a system line such as a join, and a new day each start a new group.

## Known limits

- The desktop change was checked with its unit test. The iOS unit test was updated and runs in CI. Neither was looked at in a running app before the release.
- The limit is fixed; there is no setting for it.
- The iOS app is still built with the iOS 26 SDK.
