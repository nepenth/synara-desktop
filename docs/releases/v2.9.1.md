# Synara 2.9.1

Synara 2.9.1 shows Hermes Agent's clarifying questions as cards you can answer with a tap, gets draft sync running on devices that recovered with a backup restore, and fixes a Linux crash when picking someone to mention, slash commands typed out in full, and long messages spilling out of the iOS composer.

## Desktop

- Question cards: when Hermes asks a question, Synara shows a card with a button per choice, an "Other" field for your own answer and Skip. It works with today's Hermes text questions, and with structured question cards once Hermes sends them. Someone else's question shows read-only.
- Mentions: picking someone from the @ list no longer crashes the screen on Linux ("Cannot resolve a DOM node from Slate node"). Mentions no longer get a matrix.to link preview.
- Slash commands typed out in full (`/kick @name:server`, `/me waves`) now run instead of being sent as text. An unknown command is refused, not sent. `/remove` works as Element's name for `/kick`.
- Drafts: sync now starts after restoring encryption backup with your recovery key, and Settings → General says when this device is not syncing yet and where to enter the key. A device without the key no longer tries, and fails, to save on every keystroke.

## iOS and iPad

- Question cards, the same as on desktop.
- The composer keeps a long message inside its box and scrolls, instead of spilling over the top and bottom when the keyboard is up.
- Approving or denying an agent action no longer shows a "decision sent" alert; the card shows the decision.
- Drafts: sync starts after a backup restore, and Settings → Security & Recovery says when it is not syncing yet. Mentions no longer get a link preview.

## Security

- vodozemac, the end-to-end encryption library, is updated to 0.11.2, which wipes secret keys from memory reliably again (RUSTSEC-2026-0445, RUSTSEC-2026-0451).

## Distribution

The coordinated tag workflow validates the release and publishes signed and notarized macOS downloads and updater metadata, Linux APT and pacman packages, Windows installers (checked to launch to the sign-in screen first), and the internal iOS TestFlight build.
