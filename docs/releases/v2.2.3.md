# Synara 2.2.3

Synara 2.2.3 shows what an agent approval is asking for directly on the notification, and redesigns sign-in.

## Approvals

- Agent approval notifications on macOS, Linux and iOS show the reason and the requested command, for example "forge: find -delete" with the command below it, next to Approve once and Deny. Secret-like values are redacted.
- A new Show Approval Details setting, on by default and separate from message previews, returns approval notifications to room-only text when turned off.

## Sign-in

- Login, registration and password reset are redesigned with an animated Synara mark, a brand panel and a glass card that follow your system light or dark theme and stack on narrow windows.
- Changing the homeserver no longer makes the username and password fields blink or clears what you typed. A status line under the server field shows Connecting, Connected or a short error with Retry, and Sign in waits until the new server is ready.

## Distribution

The coordinated tag workflow validates the release and publishes signed/notarized macOS downloads and updater metadata, Linux APT and pacman packages, and the internal iOS TestFlight build.
