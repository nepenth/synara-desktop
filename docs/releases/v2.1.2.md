# Synara 2.1.2

Synara 2.1.2 is a coordinated macOS, Linux, and iOS product release. It adds
Element-like fenced code in chat, favorites and sortable rooms, iOS session
restore and draft attachments, Discord-like themed chrome, and a faster
release path.

## Fenced Code

- Desktop native timeline renders Matrix formatted code as a distinct
  monospace panel with Prism syntax highlighting and a left line-number
  gutter.
- Inline code stays inline. Unknown languages still get the panel and
  numbers.
- iOS code blocks keep the monospace panel and now draw a matching
  line-number gutter.

## Rooms And Favorites

- The Recent (24h) section is gone. Favorites use Matrix `m.favourite`
  tags. The remaining rooms list is sortable by activity or name.

## iOS Session, Composer, And Settings

- After a TestFlight update, a restorable session keeps live sync instead of
  requiring another login. Connection chrome reflects start, catchup, and
  failure, with Sign Out when restore cannot continue.
- The plus button and paste add image and file drafts to the composer.
  Nothing uploads until Send.
- Settings leads with native SAS verification, shows the account avatar from
  the server, and drops controls that were not backed by a real product path.

## Theme

- Dark and light chrome uses stacked greys (rail, room list, chat) tinted by
  a user-chosen base color. Lightness of the pick is mapped onto those
  stops; it is not used as a fill.

## Release Path

- A tag that already passed Quality gate on that SHA reuses the proven
  result instead of rerunning hour-long desktop and iOS suites before
  packaging.
- Version-only bumps skip iOS, Synapse, and `cargo test`. GitHub Release
  does not wait on TestFlight promotion.

## Upgrade Notes

- Existing native sessions should restore normally.
- macOS updates through the Tauri updater. Linux updates through the pacman
  repo or the `.deb`. iOS updates through TestFlight.

## Validation

The release is gated by renderer lint and type checking, modernization tests,
Rust workspace and desktop-shell tests, dependency audits, iOS simulator tests,
macOS bundle validation, Linux Debian and Arch package validation, and live
disposable-homeserver Matrix proofs when those jobs are in scope.
