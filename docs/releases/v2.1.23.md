# Synara 2.1.23

Synara 2.1.23 repairs several cross-client operating paths while improving
desktop identity, navigation depth, Linux packaging, and iOS text interaction.

## Desktop Navigation And Inbox

- The Home header now identifies the authenticated Matrix homeserver instead
  of displaying a generic `Home` label.
- Interactive primary-rail controls use the shared restrained depth hierarchy,
  with explicit selected and keyboard-focus states.
- Inbox responses are validated at the network boundary. Error-shaped or
  malformed payloads now fail explicitly, while valid entries remain usable
  when an unrelated entry is malformed.

## Read State

- Automatic read submission now targets the Matrix SDK timeline's authoritative
  latest event and sends the same event as both the fully-read marker and the
  private read receipt.
- Hidden membership and state events can re-arm the read path without becoming
  visible timeline rows.
- Focus, visibility, live-bottom position, manual-unread state, and paint proof
  are coordinated before submission, avoiding premature or duplicate receipts.

## Rich Clipboard Transfer

- Desktop paste remains owned by WKWebView on macOS and WebKitGTK on Linux.
- Safe HTML preserves lists, emphasis, and normal links in both Markdown and
  non-Markdown composers.
- Unsafe URLs and stripped content degrade safely, oversized input is bounded,
  and rejected recognized HTML cannot fall through to an unbounded browser
  default paste.

## iOS Text Selection

- Message menus now include a dedicated Select Text action and consistent icons
  for Copy, Reply, Thread, Edit, React, Pin, and Redact.
- The selection view exports plain text and sanitized HTML, supports Dynamic
  Type and VoiceOver, and disables active links while selecting.
- Spoilers remain physically absent from the selectable projection until the
  user explicitly reveals them; Copy All remains unavailable while concealed.

## Linux Presentation And Diagnostics

- Debian, Arch, and Tauri packages include reviewed 16, 24, 32, 48, 64, 128,
  256, and 512 pixel app icons plus the scalable symbolic asset.
- Desktop diagnostics report WebKitGTK's actual hardware-acceleration policy,
  smooth-scrolling setting, software-rendering overrides, and DMABUF fast-path
  state without forcing platform behavior.

## Validation

- The protected Quality gate passed Node, Rust, dependency-audit, and full iOS
  simulator/device-Release validation.
- Desktop Package Smoke passed macOS, Linux `.deb`, and Linux Arch builds.
- The modernization suite passed 871 tests, and the focused exact-event receipt
  and iOS selection/copy regressions passed.
- Grok 4.6 High completed the final implementation review with no blockers.

## What To Test

- On Pop!_OS, confirm the launcher and desktop-bar icon remain sharp at the
  configured scale and the left navigation rail shows restrained hover/selected
  depth.
- Confirm Home displays the connected homeserver, Inbox opens without an
  exception, and a newly read room clears its unread state without manual help.
- Copy a formatted list or linked passage into the desktop composer and confirm
  its structure survives editing and sending.
- On iOS, use Select Text on formatted and spoiler-bearing messages and confirm
  concealed spoiler content cannot be copied before Reveal Spoilers.
