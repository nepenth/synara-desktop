> **Strict acceptance open.** Pure in-memory projection indexes; no live SDK wiring or send.

## Summary

- `PollIndex` stores ordered poll rows keyed by room id and poll event id
- Poll rows contain the plain question, closed state, and stable response counts by answer id
- `StateProjectionIndex` stores ordered room state/membership summary rows
- Membership targets retain a localpart only, never a full Matrix user id
- Same-key upsert replaces, room/event removal is explicit, and rooms remain isolated
- Generation retirement wipes both indexes on logout/account switch
- Plaintext-bearing rows and indexes implement neither `Debug` nor `Display`
- Marker: `matrix-polls-p5.7`

## Out of scope

- Live SDK timeline/event mapping, sync wiring, and `Room::send`
- Poll creation, response, or end network operations
- Production IPC/Tauri commands and UI
- Crypto, media bytes, token migration, or dual-backend behavior
- Full room state storage or full Matrix user ids in membership summaries
