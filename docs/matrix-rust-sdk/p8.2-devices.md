## Current owner

The earlier in-memory `DeviceIndex` harness was replaced in V-CRYPTO.7 by the
live managed-session route documented in
[v-crypto-7-device-list-trust.md](v-crypto-7-device-list-trust.md):

- authoritative device rows from `Client::devices`;
- cross-signing trust joined from `Encryption::get_user_devices`;
- demand-driven mount/refocus reads and a supported `devices_stream` refresh
  trigger for documented new/changed entries;
- native rename and other-device deletion with authoritative readback;
- purpose-specific Password/SSO UIAA continuation owned by Rust.

The old `DeviceIndex`, soft-cap, `mark_deleted`, and harness-only tests are no
longer production evidence and have been physically deleted. The live route
does not use raw Matrix HTTP, raw sync, polling, or lower-level crypto-machine
access.

## Evidence state

Focused compile/typecheck evidence is recorded in the V-CRYPTO.7 document.
Live multi-session/UI proof is not claimed by the local candidate.
