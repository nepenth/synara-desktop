## Executive summary

This task **expands IPC protocol contract tests** for the versioned Matrix IPC
foundation (plan § Phase 1 P1.5 + §6.3 / §6.4). It does **not** introduce
production login/sync, dual-backend selection, SDK wire types, or new Tauri
Matrix product commands.

**In scope:**

- Serialization round trips (envelope + all 13 kinds + 21 error categories)
- Unknown variants / unknown kind rejection
- Invalid payloads (missing required fields, wrong types, kind-specific fields)
- Policy bounds (payload size, stream queue depth, open streams, coalesce window)
- Sequence gaps → `resync_required` path
- Stale session generation rejection → error / `resync_required`
- Schema compatibility via shared JSON fixtures (Rust + TypeScript)
- Light P1.4 DTO composition (snapshot body carries `RoomSummary`-shaped JSON)

**Out of scope (explicit):**

- Production Matrix login/sync/Client construction
- Tauri `invoke_handler` registration for Matrix product commands
- Switching the frontend off `matrix-js-sdk`
- Dual-backend / SDK selector
- Live stream supervisor / resource cleanup actor — Phase 2+
- Architectural CI guardrails — **P1.6**

Product Matrix runtime remains **only** `matrix-js-sdk`.

## 3. Policy constants (asserted exact)

| Constant | Value | Notes |
|----------|------:|-------|
| `MATRIX_IPC_PROTOCOL_VERSION` | `1` | Negotiation baseline |
| `MAX_ENVELOPE_PAYLOAD_JSON_BYTES` | `1048576` (1 MiB) | Soft upper bound; chunk/handle beyond |
| `MAX_STREAM_QUEUE_DEPTH` | `256` | Soft queue bound before backpressure/coalesce |
| `STREAM_COALESCE_WINDOW_MS` | `16` | Documented coalesce window |
| `MAX_OPEN_STREAMS_PER_SESSION` | `64` | Concurrent stream bound |
| `FORBID_MEDIA_BYTES_OVER_JSON_IPC` | `true` | Media via handles only |

Helpers (pure, no live queue):

- Rust bool: `payload_within_bounds`, `stream_queue_depth_within_bounds`, `open_streams_within_bounds`
- Rust Result: `check_payload_json_bounds`, `check_stream_queue_depth`, `check_open_streams` (`sdk_invariant`)
- TS bool: `payloadWithinBounds`, `streamQueueDepthWithinBounds`, `openStreamsWithinBounds`
- TS error: `checkPayloadJsonBounds`, `checkStreamQueueDepth`, `checkOpenStreams`

Envelope boundary: Rust rejects non-object `payload` values (mirrors TS `isObject`).
