## Executive summary

This task adds **CI-enforced architectural guardrails** for the Matrix Rust SDK
full replacement (plan P1.6). Checks prohibit SDK types on DTO/IPC surfaces,
matrix-js-sdk imports into greenfield contracts, raw `/_matrix/` HTTP in those
contracts, dual-backend selectors, unversioned Matrix IPC, production
Client/login/sync under `src-tauri/src/matrix/`, and premature Matrix product
Tauri commands.

**In scope:** guardrail script, unit tests with prohibited fixtures, npm + CI
wiring, design note.

**Out of scope:**

- Production Matrix login/sync/Client construction
- Removing existing `matrix-js-sdk` product usage (still sole runtime)
- Phase 2 supervisor / secure storage
- Merging to `main`

Product Matrix runtime remains **only** `matrix-js-sdk` until later cutover.

## 2. Rules

| Rule id | Surface | Forbidden |
|---------|---------|-----------|
| `no-sdk-types-in-dto-ipc` | `src-tauri/src/matrix/{dto,ipc}/**` | `matrix_sdk` / `matrix_sdk_ui` / `ruma` use or path types |
| `no-js-sdk-in-greenfield-contracts` | `synara/.../matrix-ipc/**`, `matrix-dto/**` | `matrix-js-sdk` imports |
| `no-raw-matrix-http-in-contracts` | greenfield TS contracts (non-test) | `/_matrix/` strings / path helpers |
| `no-deepening-direct-client-in-contracts` | greenfield TS contracts | `mx.http`, `MatrixClient`, etc. |
| `no-production-matrix-client-in-matrix-module` | `src-tauri/src/matrix/**` (non-test) | `Client::builder`, login/sync/restore APIs |
| `no-dual-backend-selector` | `synara/src/**`, `src-tauri/src/**` (non-test) | `MatrixBackend`, `matrixBackendSelector`, dual-backend flags |
| `versioned-matrix-ipc` | IPC version modules | Missing `MATRIX_IPC_PROTOCOL_VERSION` |
| `no-matrix-product-tauri-commands` | `src-tauri/src/lib.rs` invoke_handler | Any `matrix_*` command registration |

**Explicitly allowed:**

- Product `matrix-js-sdk` usage outside greenfield contract packages
- `matrix_sdk_link_smoke` (outside `matrix/dto` + `matrix/ipc`) for compile-only SDK linkage
- Doc comments that *mention* SDK names (comments stripped before scanning)
- Existing desktop REST exceptions via legacy `check-matrix-boundaries` allowlist

   P1.6 `runGuardrails`.

checker; the live repository **must pass**.
