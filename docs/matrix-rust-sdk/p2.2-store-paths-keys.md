## Executive summary

This task implements the **per-account Matrix store path layout** and **store
encryption key** foundation (plan Phase 2 / P2.2, §8.2–8.3):

- Derive isolated directories from a non-secret `AccountIdentity`
- CSPRNG 32-byte `StoreKeyMaterial` with redacted debug + best-effort zeroize
- Abstract `StoreKeyVault` (in-memory harness; keyring naming contract)
- Collision tests: two accounts cannot share path or key id
- `ensure_dirs` is create-only (never auto-wipes on failure)

**Out of scope:** live `matrix_sdk::Client` builder (**P2.3**), production
keyring session wiring, destructive wipe against disk (**P2.6**), production
Tauri commands, dual-backend.

Product Matrix runtime remains **only** `matrix-js-sdk`.

## 2. Path layout

Under `{app_data_root}/matrix/{account_segment}/`:

| Subdir | Role |
|--------|------|
| `state/` | SQLite state store (P2.3+) |
| `crypto/` | Crypto store (P2.3+) |
| `cache/` | Event cache |
| `media/` | Media cache |

`account_segment` = `{sanitized_localpart}_{fnv1a64_hex(user_id|homeserver)}`.

Traversal (`..`, `/`, `\`) rejected. Unix dirs created as `0o700`.

---

## 3. Store keys

| Type | Role |
|------|------|
| `StoreKeyMaterial` | 32-byte CSPRNG key; `Debug` redacted |
| `StoreKeyId` | Keyring service `com.whylandcreative.synara.desktop.matrix-store-key` + account `store-key:{segment}` |
| `StoreKeyVault` | `get` / `set` / `delete` |
| `InMemoryStoreKeyVault` | Unit tests |
| `KeyringStoreKeyRefs` | Stable naming contract (live Entry deferred) |
| `get_or_create_store_key` | Miss → generate + store; **never** deletes dirs |

Session credential account (`matrix-session`) is intentionally distinct.

---

## 4. Constraints

| Constraint | How |
|------------|-----|
| Two accounts cannot share path/key | Collision unit tests |
| Store failures do not auto-delete | No wipe API in this module; `ensure_dirs` create-only |
| No dual-backend | No selector; no JS crypto store path |
| No production Client builder | No SDK store open |
| Secrets not logged | Redacted `Debug`; layout JSON paths only |
