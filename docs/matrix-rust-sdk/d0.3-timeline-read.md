# D0.3 — native opened-room timeline substrate (retired cutover claim)

## Outcome

This record originally described a slim native text renderer and polling
cutover. That cutover was withdrawn: replacing `RoomTimeline.tsx` with a flat
snapshot lost retained timeline behavior, so it is not an acceptable full
Matrix Rust SDK replacement.

The retained D0.3 substrate is still useful: Rust owns a managed
`matrix-sdk-ui::Timeline` per opened room beside the live `Client` and
`SyncServiceOwner` introduced by D0.1/D0.2. It provides bounded native
open/snapshot/pagination/event-readback foundations while the complete
`TimelineViewSnapshot` and delta/presenter path is built. The legacy
`RoomTimeline.tsx` remains the only active desktop timeline presenter until one
complete native cutover can delete it physically; there is no selector,
fallback, or dogfood route.

## Commands

- `matrix_timeline_open(request)` validates the room, creates or reuses its
  live SDK timeline, and returns the current bounded snapshot. Its typed
  initial position preserves `live_bottom` or an event-link `focused(eventId)`
  request at the Rust owner boundary.
- `matrix_timeline_snapshot(room_id)` returns the current projection for an
  already-open timeline. It is an unactivated foundation, not a polling
  presenter API.
- `matrix_timeline_paginate(room_id, dir)` paginates the retained SDK timeline
  in `backwards` or `forwards` direction and returns the updated snapshot.

These commands remain registered as native foundations. They do not authorize a
partial React renderer; the final presenter must consume the versioned,
SDK-neutral view snapshot and native delta stream specified in
[`v-timeline-full-replacement-contract.md`](v-timeline-full-replacement-contract.md).

## Privacy boundary

The legacy foundation DTO contains only session generation, room ID, stable
item and event IDs, sender MXID, event type, origin timestamp, display body,
and the back-pagination end flag. The target product DTO additionally has a
versioned row union, position, read, pagination, capability, and delta
contracts. Neither boundary may expose raw event JSON, encrypted content,
ciphertext, session keys, access tokens, refresh tokens, passwords, or media
bytes.

## Known residual

- There is deliberately no active native timeline renderer yet. The former
  flat renderer and polling path must not be revived.
- `TimelineViewSnapshot` projection is still incomplete for several rich,
  relation, media, state, call, read, and presentation rows; those omissions
  are cutover gates, not permission to fall back to matrix-js-sdk.
- Native subscriptions must produce ordered deltas for the final presenter;
  polling is not the final live-update owner.
- The focused-event UTD readback bridge is retained only for V-CRYPTO.6 and is
  deleted together with the legacy row path during final V-TIMELINE cutover.
- Sending and all visible timeline actions need their own typed native owner
  and authoritative readback before their affordance is shown in the final
  presenter.
