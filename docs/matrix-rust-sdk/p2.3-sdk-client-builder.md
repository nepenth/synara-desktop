## Executive summary

This task implements the **Matrix Rust SDK client builder foundation** (plan
Phase 2 / P2.3):

- Product-default `ClientBuildConfig` (homeserver URL, network/proxy policy,
  user agent, timeouts, store layout, optional store key)
- Approved Cargo features: `matrix-sdk` `sqlite` + `bundled-sqlite` (exact
  `=0.18.0`); `e2e-encryption` remains via UI unification (P1.2)
- `build_unauthenticated_client` — sole production `Client::builder` site under
  `src-tauri/src/matrix/`
- `SdkClientHandle` for supervisor install/drop cycles
- Guardrail update: allow `Client::builder` only under `matrix/client_builder/`;
  still ban login/sync/restore everywhere under `matrix/`
- Unit + harness tests (offline SQLite open/reopen; supervisor install)

**Out of scope:** production login/sync loop, discovery-based homeserver modes
in product defaults, media store wiring, SSO/local-server features, dual-backend,
Matrix Tauri commands, frontend cutover.

Product Matrix runtime remains **only** `matrix-js-sdk`.

## 2. Configuration surface

| Component | Role |
|-----------|------|
| `ClientBuildConfig` | Identity + `StorePaths` + policies + optional `StoreKeyMaterial` |
| `HomeserverMode::ExplicitUrl` | `ClientBuilder::homeserver_url` (no well-known at build) |
| `NetworkPolicy` | Optional HTTP proxy; **SSL verification required** |
| `TimeoutPolicy` | Default 30s request timeout, retry limit 3 |
| `default_user_agent()` | `Synara-Desktop/{crate_version} (matrix-sdk/0.18.0)` |
| `ClientBuildPlan` | Diagnostic JSON (paths + flags; **never** keys/tokens) |

Store open uses P2.2 layout:

- state/crypto path → `state_dir`
- event-cache path → `cache_dir`
- passphrase → hex of 32-byte store key (when present)

## 4. Construction rules

```
build_unauthenticated_client(&ClientBuildConfig)
  → Client::builder()
      .homeserver_url(...)
      .sqlite_store_with_cache_path(state, cache, passphrase?)
      .user_agent(...)
      .request_config(...)
      .proxy?(...)
      .handle_refresh_tokens?(...)
      .with_encryption_settings(Default)
  → Client  (not logged in; no sync)
```

- **No** `login_*`, `matrix_auth`, `restore_session`, `sync_*` in this module
- `ensure_dirs` is create-only (inherits P2.2 no-auto-wipe)
- Supervisor still installs handles only via `ClientFactory` (harness proves
  `SdkClientHandle` path)
