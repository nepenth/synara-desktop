## 2. Envelope (plan §6.3)

Wire shape (camelCase fields; snake_case `kind`):

```json
{
  "protocolVersion": 1,
  "sessionGeneration": 1,
  "streamId": "stream-room-list-1",
  "sequence": 2,
  "requestId": "req-optional",
  "kind": "delta",
  "payload": { }
}
```

| Field | Required | Notes |
|-------|----------|-------|
| `protocolVersion` | yes | Constant `1` for this foundation |
| `sessionGeneration` | yes | Stale-generation rejection when ≠ live |
| `streamId` | where applicable | Stream-scoped messages |
| `sequence` | yes | Monotonic per stream (or control channel) |
| `kind` | yes | Discriminator |
| `payload` | yes | Bounded; domain bodies opaque until P1.4 |
| `requestId` | optional | Correlation for request/response |
| timestamp | omitted | Only when a future product semantic requires it |

Rust: `MatrixIpcEnvelope` + adjacently-tagged `MatrixIpcMessage`
(`#[serde(tag = "kind", content = "payload", rename_all = "snake_case")]`).

TypeScript: exhaustive discriminated union on `kind` + `parseMatrixIpcEnvelope`.

## 3. Kind list (control surface only)

| Kind | Direction (conceptual) | Role |
|------|------------------------|------|
| `hello` | client → host | Version negotiation |
| `hello_ack` | host → client | Negotiated version + generation |
| `subscribe` | client → host | Open stream |
| `unsubscribe` | client → host | Close stream / cleanup hook |
| `subscribed` | host → client | Subscribe ack |
| `unsubscribed` | host → client | Unsubscribe ack (`resourcesReleased`) |
| `snapshot` | host → client | Initial stream state (then deltas) |
| `delta` | host → client | Ordered update; duplicate idempotent |
| `resync_required` | either | Gap / stale gen / unknown → resubscribe |
| `cancel` | either | Cancellation token for long-running work |
| `error` | host → client | Stable error category payload |
| `ping` / `pong` | either | Optional liveness |

Domain command kinds (login, send, etc.) are **not** introduced here.

### Stream topics (scaffold strings)

`room_list`, `timeline`, `members`, `typing`, `receipts`, `account_data`,
`presence`, `notification_candidates`, `crypto_status`, `send_queue`.

### Unknown-kind policy

- **Commands / requests at the boundary:** reject (deserialization fails /
  `parseMatrixIpcEnvelope` returns `null`).
- **Stream events with invalid generation or sequence:** do not forward;
  signal `resync_required` (and/or `error` with `stale_session_generation`).

## 4. Protocol behaviors (types + pure helpers)

| Behavior | Implementation |
|----------|----------------|
| Snapshot then ordered deltas | Sequence baseline = snapshot `sequence`; deltas must be last+1 |
| Stale-generation rejection | `check_session_generation` / `checkSessionGeneration` |
| Duplicate-delta idempotence | `sequence == last` → `Duplicate` / ignore |
| Gap detection + resubscribe | `sequence > last+1` → `Gap` + `resync_required` |
| Deterministic unsubscribe / cleanup | Lifecycle states + `resourcesReleased` on `unsubscribed` |
| Bounded queues / coalescing | Constants: `MAX_STREAM_QUEUE_DEPTH=256`, `STREAM_COALESCE_WINDOW_MS=16`, `MAX_ENVELOPE_PAYLOAD_JSON_BYTES=1MiB` |
| Cancellation tokens | `cancel` kind + `cancellationToken` field |
| No large media over JSON IPC | `FORBID_MEDIA_BYTES_OVER_JSON_IPC = true` (document + constant) |

## 5. Error model (plan §6.4)

Stable enum categories (snake_case on wire):

`authentication_rejected`, `user_deactivated`, `interactive_auth_required`,
`forbidden`, `rate_limited` (+ `retryAfterMs`), `connectivity`,
`homeserver_unavailable`, `unsupported_capability`, `store_locked`,
`store_corrupt`, `store_unavailable`, `crypto_failure`, `recovery_failure`,
`verification_failure`, `media_too_large`, `media_unsupported`,
`media_decrypt_failed`, `cancellation`, `stale_session_generation`,
`sdk_invariant`, `unknown` (+ privacy-safe `diagnosticId`).

**Privacy:** error types expose only category, optional short message,
`diagnosticId`, `retryAfterMs`, `requestId`. No tokens, credentials, recovery
keys, event plaintext, raw push payloads, or decrypted media fields. TS parser
rejects secret-looking keys at the boundary.
