> **Strict acceptance open.** Pure metadata policy harness; no filesystem cache
> access and no media or event bytes.

## Summary

- `RetentionPolicy` defines an entry cap, an optional last-access TTL, and
  encrypted-media purge behavior for logout.
- `EntryMeta` carries only an opaque local handle id, last-access seconds, and
  whether the handle is known to contain encrypted-room media.
- `plan_purge` returns a `PrivacyPurgePlan` of unique opaque handles for the
  cache host to delete. It never deletes anything itself.
- Age expiry, encrypted-only logout purge, and LRU entry-cap cleanup form one
  union. The entry cap is evaluated after age and privacy candidates.
- Plans are deterministic: oldest access first, with handle id as a tie-breaker.
- Opaque handles are redacted from `Debug` output.
- Marker: `matrix-media-cache-policy-p7.6`.

`purge_on_logout` is the policy switch supplied when planning logout cleanup.
When enabled, it adds encrypted-only entries to the purge plan; unencrypted
entries remain subject to normal age and entry-cap retention. This keeps the
pure function independent of lifecycle and filesystem implementations.

An entry expires when its age is greater than or equal to `max_age_secs`.
Future host timestamps are treated as age zero. A TTL or entry cap of zero
purges every distinct entry.

## Coordination with P7.3

The harness intentionally does not depend on the P7.3 media-cache index being
present on the branch. A future adapter can project index records into
`EntryMeta`, execute the returned opaque handle plan, and then update the index.

## Privacy boundary

- No media bytes, ciphertext, event plaintext, tokens, recovery keys, or key
  material are accepted or returned.
- No filesystem paths or delete operations are performed.
- No production Tauri command, Matrix SDK media call, or dual-backend selector
  is introduced. Product runtime remains `matrix-js-sdk` until cutover.

## Acceptance

- Unit tests cover TTL boundaries, future timestamps, LRU caps, deterministic
  ties, encrypted-only logout purge, combined rules, zero limits, duplicate
  handles, and debug redaction.
- `cargo test matrix::media_cache_policy`
- `cargo clippy --all-targets --all-features -- -D warnings`
