## Executive summary

This task implements the **task supervision and cancellation foundation** (plan
Phase 2 / P2.4):

- Standalone `TaskSupervisor` registry under `src-tauri/src/matrix/tasks/`
- Task kinds: `Sync`, `Listener`, `Upload`, `Search`, `Generic`
- Session-generation stamping on spawn/register; refuse stale spawn + results
- Cancel / join / cancel-and-join; `retire_stale` / `retire_generation` /
  `shutdown_all`
- Bridge with pure P2.1 lifecycle actor via `follow_supervisor_generation`
  (async cancel+join after generation bumps)
- Deterministic unit tests: double-cancel, race cancel of long-running futures,
  leak-free open/close cycles, logout/wipe/fail-reopen generation isolation

**Out of scope:** production login/sync loops, product Tauri Matrix commands,
dual-backend, live homeserver network, media/search product wiring (later
phases own the real futures; this registry only supervises them).

Product Matrix runtime remains **only** `matrix-js-sdk`.

## 3. Invariants

1. **Live-generation spawn only** — `spawn` / `register` require
   `generation == live_generation` or return `SpawnStaleGeneration`.
2. **Stale-result refusal** — `accept_result` / `accept_task_result` reject
   superseded generations (`StaleGeneration`).
3. **Idempotent cancel** — second cancel or cancel-after-terminal is a no-op;
   unknown id still errors.
4. **Generation bump + retire** — `bump_generation` advances live epoch;
   callers must `retire_stale` (or `follow_supervisor_generation`) so old work
   cannot complete into a new epoch.
5. **Shutdown empties registry** — `shutdown_all` cancel+joins every task.
6. **No secrets** — errors and `TaskInfo` carry only ids, kinds, generation,
   run state (no tokens, paths, or payloads).

## 4. Lifecycle composition

```
MatrixSupervisor.apply(CompleteLogout | CompleteWipe | BeginOpen after Fail)
  → session_generation advances
follow_supervisor_generation(&mut tasks, &actor)
  → tasks.set_live_generation(target)
  → tasks.retire_stale().await   // cancel + join gen != live
```

`mirror_generation` is tests-only setup (set live without retiring).
