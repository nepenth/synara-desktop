## Summary

- `RoomSummary`: `is_favorite`, `is_low_priority`, `folder_id` (serde defaults)
- Scopes: `Favorites`, `LowPriority`
- `folder_id` is the user room folder (`in.synara.room_folders`), filled by
  room-list snapshots since the room-folders work; the old
  `select_rooms_in_folder` helper is gone. Sections, order and unread for
  folders come from `presentation.folders` and the `room_section_placement` rule:
  see [`docs/design/room-folders.md`](../design/room-folders.md).
- Sorts: by name, recent activity (`last_activity_ts`), favorites-first, low-priority-last
- Product lists: Favorites (`m.favourite`) plus remaining rooms; no recents rail
