## Limitations

1. Probes are compile-only API-shape checks. They do **not** prove network, sync,
   encryption, store, or homeserver semantics.
2. This is the P0.3a foundation only. The full P0.3 capability dossier is out of
   scope for this subtask.
3. No experimental `matrix-sdk` features were requested or enabled.
4. `e2e-encryption` appears on `matrix-sdk` only through transitive feature
   unification from `matrix-sdk-ui`, not as a direct probe request.
5. `sqlite` and `automatic-room-key-forwarding` are neither requested nor
   resolved as `matrix-sdk` features here.
6. Generated rustdoc HTML must not be committed.
7. Production Cargo manifests (including `src-tauri/Cargo.toml`) are
   intentionally unchanged and must not depend on `matrix-sdk` yet.
