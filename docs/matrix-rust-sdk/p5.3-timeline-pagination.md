## Summary

- `TimelinePagination` per stream key + session generation
- Directions: `Backwards` / `Forwards` with independent phases
- Phases: `Idle` → `InFlight` → `Idle` | `Exhausted` | `Failed`
- Requests carry limit only (1..=100); outcomes report counts + exhausted flag
- Items still arrive via P5.2 delta projection (not embedded in outcomes)
- Generation retire cancels in-flight pages with privacy-safe diagnostic

## Out of scope

- SDK Timeline attach or real network pagination
- Virtualization windowing / UI scroll policies
- Production Tauri commands, dual-backend, tokens in logs
