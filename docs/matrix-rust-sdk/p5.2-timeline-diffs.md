## Summary

- `TimelineDeltaOp` / `TimelineDeltaBatch` / `TimelineSnapshot` — ordered ops
  mirroring `eyeball_im::VectorDiff` semantics with product DTOs only.
- `TimelineProjection` — pure state machine: sequence gaps + generation mismatch
  force resync until a `Reset` batch lands.
- Extends P5.1 registry errors with `ResyncRequired` / `InvalidDelta`.
- Marker: `matrix-timeline-registry-p5.1+diffs-p5.2`.

## Out of scope

- Constructing or attaching SDK `matrix_sdk_ui::timeline::Timeline`
- Live event mapping from SDK diffs → `TimelineItem` (host adapter later)
- Pagination / virtualization windowing (P5.3+)
- Dual-backend, tokens in logs/IPC, plaintext event dumps in errors
