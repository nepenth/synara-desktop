## Defects Closed During Proof

- Added a stable timeline snapshot operation instead of forcing pagination for
  current-state reads.
- Coordinated room subscriptions so the active room and first room-list
  viewport remain subscribed without replacing one another.
- Removed misuse of the SDK recency stamp as a Unix timestamp.
- Added safe agent-event room previews instead of raw JSON.
- Added the missing Tauri capability for timeline snapshots.
- Removed automatic iOS test retries and made CI run the exact
  build-for-testing artifacts.
- Preserved the committed Swift package lock across XcodeGen.
- Stabilized composer focus/keyboard behavior, session reset sequencing, and
  live visual assertions.
