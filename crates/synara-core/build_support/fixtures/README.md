These fixtures are actual, unpatched Rust scaffolding generated by the locked
UniFFI 0.32.2 bindgen CLI from the adjacent UDL files. The proof crate was named
`synara_uniffi_shape_proof`, which determines the generated metadata/checksum
names. Regenerate with that crate's `Cargo.toml` and `src/lib.rs` present:

```sh
synara-core-bindgen scaffolding src/mixed.udl --out-dir .
synara-core-bindgen scaffolding src/callback.udl --out-dir .
```

A mixed object emits separate export impls for its constructor, synchronous
method, and asynchronous method. Synara patches the one asynchronous export.
The current generator emits a synchronous callback trait even when its UDL has
an `[Async]` declaration. Synara does not support that callback shape: the
bridge rejects the mismatch before any output is written. Current product
callbacks are synchronous. These fixtures test transformation and rejection;
they do not establish compiled Apple ABI compatibility.
